# 🧩 기능 카탈로그 (개요)

알뜰이 제공하는 기능의 **개요·인덱스**입니다. 앱은 **두 모드**로 나뉘며, 상세는 모드별 문서를 보세요. 데이터 구조는 [data-model.md](data-model.md), 함수 위치는 [code-structure.md](code-structure.md) 참고.

| 모드 | 무엇 | 상세 문서 |
|---|---|---|
| 💰 **가계부** | 개인·그룹 공유 가계부(거래·자산·카드실적·예산·구독·목적별·정산·경조사비·대출) | [features-ledger.md](features-ledger.md) |
| ✅ **할일** | 개인/그룹 공유 할일(프로필별 관리·친구 공유·담당 배정·반복·여행 연동) | [features-todo.md](features-todo.md) |

## 모드 전환 / 화면 구성

- **상단바**: **모드 토글**(`[가계부 | 할일]`, `setMode` — `localStorage('mode')` 유지), **워크스페이스 칩**(현재 가계부 전환), **펫캠 토글**, **테마 토글**(🌙/☀️). 상단바 아래엔 **알뜰홈 dock**(걸어다니는 도트 고양이 + 은화)이 상시 노출됩니다.
- **하단 탭바**는 모드별로 바뀝니다(`renderTabBar` / `_TABSETS`). 가운데 **＋** FAB는 모드에 따라 거래 추가/할일 추가로 분기(`fabAdd`). **더보기**는 두 모드 공용 진입점이지만 모드에 맞는 메뉴를 보여줍니다(`renderMore` 분기).
- **오늘 홈(랜딩)**: 상단 **로고=홈 버튼**(`goHome`)으로 진입하는 오늘 대시보드(오늘 미션·할일·지출 한 줄). 모드 화면에 있을 때 **오늘 미처리가 있으면 로고에 작은 점 배지**로 알려 순회 부담을 줄이고, 다 처리하면 **완료 카드**(고양이 + 1회 축하 연출, `prefers-reduced-motion` 정적)로 끝맺음을 줍니다. 남은 일 계산은 단일 순수 헬퍼 `todayPending`(util.js).

## 💰 가계부 모드 (요약)

개인·그룹이 함께 쓰는 공유 가계부. **거래 9종**(수입/지출/이체/충전/선불결제/환불/포인트±/잔액조정)을 기록하고, 달력·리포트로 보고, 자산·카드실적·예산·정기결제·구독·목적별 가계부·정산·경조사비·대출·적금을 관리합니다. **소비 대상(개인/공동) 분리 집계**, **해외통화(여행) 실시간 환율**, **CSV 내보내기** 지원.

→ 전체 내용은 **[features-ledger.md](features-ledger.md)**.

## ✅ 할일 모드 (요약)

개인이 **프로필별로 할일**(user-global — 워크스페이스와 무관하게 항상 동일, `users/{uid}/todos`)을 관리하고, **친구 코드로 친구를 맺어** '할일 공개'를 켠 친구의 할일을 읽기전용으로 봅니다. **그룹 할일**로 여행·모임의 담당을 나눕니다. **스코프는 그룹전환(컨텍스트)이 결정** — **개인 프로필=내 할일, 그룹=그룹 할일**(개인/그룹 세그먼트 폐지, 개인용은 그룹전환에서 '개인 프로필' 선택). 개인 프로필일 때만 상단 **[내 할일 | 친구들] 토글**로 **친구들 피드**(공개 친구 아바타·오늘 무지개 테두리·친구 할일 목록, 친구 관리는 더보기 공용)를 봅니다. 마감 캘린더·반복·목적별(여행) 연결·완료 시 **은화 보상** 제공.

→ 전체 내용은 **[features-todo.md](features-todo.md)**.

## 🐱 알뜰홈 (은화 경제 — 게임화)

가계부·할일 활동으로 **은화**를 모아 **고양이**를 입양·구경하는 게임화 기능. 소속은 **개인 전역**(`users/{uid}/game`)이라 개인↔그룹을 오가도 내 고양이/은화가 따라옵니다. 자세한 기획은 [cat-feature-plan.md](cat-feature-plan.md).

- **은화 미션**: 일일 미션 — **고정 2종**(오늘 1건 기록 +50 / 출석 +50)에 더해 **날짜 시드 로테이션 2종**(`DAILY_POOL`: 카테고리+메모 채우기·거래 3건·할일 완료·펫 쓰다듬기 중 매일 2개, 각 +40)을 KST 자정 기준으로 판정, **멱등 수령**(같은 날 중복 지급 불가). 출석은 진입 시 자동 수령. 접속만 해도 받는 '기본 번들'을 크게 해 라이트·헤비 격차를 좁힘(경제 정책 [economy-policy.md](economy-policy.md)). **업적**(1회성): 첫 거래·고양이 3마리·여행 가계부·해외통화 첫 지출·첫 예산·첫 정산·**첫 할일 완료·할일 10개 완료** 등 앱 기능을 써보면 은화 지급(`ACHIEVEMENTS`, period `once`로 영구 저장). **내 미션(커스텀 습관)**: 미션 화면 '내 미션' 섹션에서 직접 추가(`openCustomMissionEdit`), **매일 체크는 무보상**·**7일 연속마다 +40 은화**(최대 5개, 개인 전역 `game/customMissions`·`game/missionLogs`, 날짜키 멱등·재지급 없음, 주간 리셋 없이 영구 지속), 🔥연속·최근7일 점 표시. 업적에 '첫 내 미션'·'7일 연속'도 포함. **매일 반복 습관은 내 미션**, **정해진 날짜 반복(매주·매월)은 할일 → 반복**으로 역할 분리(겹침 제거).

- **가챠(뽑기)**: 알뜰샵 가챠 탭(구 '이벤트') 안은 **뜰알·펫알·랜덤박스·무지개 4개 서브탭**(`_gachaTab`/`gachaTabHtml`·선택 유지)으로 나뉘어 종류별로 뽑는다(뜰알 탭=한정 픽업 배너, 각 탭 하단에 보유분 열기 — **탭별 전용 배너**: 뜰알=한정 픽업 낮 씬·펫알=노을(연못)·**랜덤박스=노을(선물상자 무더기+트윙클, `sunsetSceneHtml(mode,'box')`)**·무지개=밤). **펫알**(→고양이)·**랜덤박스**(→가구) 각 100 은화. 구매 시 화면 중앙 오픈 연출 → 등급(일반/고급/희귀/특별/전설/한정, 확률 60/20/15/3.8/1/0.2%) 랜덤 보상. 등급별 확률 고지는 **설정 → `확률 안내`**(`openProbInfoSheet`)에서 모든 뽑기(펫알·랜덤박스·뜰알·무지개)를 한 화면에 공시(배너/탭에는 미표기). **알뜰샵 고양이·가구는 등급 오름차순 정렬**이며, **특별(epic) 이상은 은화 구매 불가 → 펫은 `🥚 펫알 전용`·가구는 `🎁 랜덤박스 전용`(가챠로만)**. 열 때마다 **금화 1개**, 중복 고양이는 **그 펫 가격의 20% 은화** 환급. **✨ 무지개알·무지개박스**(가챠 탭, **각 금화 100**)는 사용 시 **특별90·전설8·한정2%** 확정. **오픈 연출은 등급색 기반 픽셀아트**로 개편 — 무대 전체가 등급색으로 틴트되어 파티클·광선·반짝임·프레임이 등급색을 따르고 **등급↑일수록 화려**, 무지개는 열기 전 **무지갯빛 반짝임**. 알이 갈라지는/박스가 열리는 순간의 빛은 **화려한 도트 방사 버스트(십자 아닌 12갈래)+은은한 디더 오오라**가 **바깥으로 살짝씩 퍼져나가는(발산)** 연출(회전 아님), 열고 나면 **펫 주변에 작고 은은한 오오라 + 둘레 트윙클 반짝임**(화면 정중앙 아님, 펫을 따라감). **🌈 처음 획득**(중복 아님)한 펫/아이템이면 등장 시 그 위에 **움직이는 무지개색 픽셀 "NEW" 배지**가 뜨고 **글자마다 물결처럼 위아래로 흔들린다**(`gachaNew`=지급 전 보유 판정 → `newBadgeSvg`/`pxSvg` RAINBOW + `.fx-new-ch`/`fxnewbob`, 무지개알/무지개박스 포함).

## 공통 기반

두 모드가 함께 쓰는 토대입니다.

- **로그인 · 인증**: 이메일/비밀번호(Firebase Auth). 로그인 화면 하단에 **아이디 저장 · 자동 로그인** 흰검 토글(`localStorage` 저장·로그아웃 후에도 유지, 기본 on). 자동 로그인 on=`LOCAL` 지속성(앱 재실행에도 로그인 유지)·off=`SESSION`(완전 종료 시 재로그인), 아이디 저장 on이면 이메일 자동 입력(`authOptGet`/`beforeAuth`). **아이디 · 비밀번호 찾기**: 로그인 화면 링크 → **로그인 도움 시트**(`openLoginHelpSheet`) — 아이디는 곧 가입 이메일이라 안내로 대체하고, 이메일을 넣어 **비밀번호 재설정 메일**(`sendPasswordReset` → `sendPasswordResetEmail`)을 받는다. (실제 발송엔 Firebase Console 승인 도메인·재설정 이메일 템플릿 설정 필요.)
- **워크스페이스(개인 프로필/그룹)**: 모든 데이터(`ws/{wsId}`)와 멤버·초대코드의 격리 단위. **개인 프로필**(`ws_{uid}`, 항상 존재)은 나만 보는 개인 가계부·할일, 그룹은 6자리 초대코드로 합류(`joinByCode`)·공동 read/write. 그룹전환(`openWorkspaceSheet`)에서 '개인 프로필' 또는 그룹 선택(`switchWorkspace`). **가계부·할일은 모드별 최근 컨텍스트를 따로 기억**(`recentWs`)해 토글해도 각자 마지막 사용처로 이어짐. 상세는 [features-ledger.md](features-ledger.md#워크스페이스-개인--그룹-공유).
- **프로필(사진/이름/비밀번호/공개)**: 더보기 프로필 줄 → **내 프로필**(`openProfileSheet`) — 사진 설정/삭제 + 별명 수정 + **계정 이메일(아이디) 표시** + **비밀번호 변경** + **프로필 공개/비공개 토글**(`users/{uid}/profilePublic`; 비공개면 랭킹·비친구에게 **은화+'알뜰'** 익명). 사진은 **256px JPEG base64**(`users/{uid}/photo`). 이름은 내가 속한 모든 워크스페이스 멤버 이름에 반영. **사진 없는 기본 아바타=은화 픽셀 아이콘**(개인, `avatarHtml`), **그룹/가계부 기본=금화**(`wsAvatarHtml`). 멤버 사진은 `loadMemberPhotos`로 캐시.
- **가계부(워크스페이스) 프로필**: 그룹 이름·사진 편집(`openWsProfileSheet`, `wsAvatarHtml`).
- **다크모드**: 토글(localStorage 저장, `applyTheme`/`toggleTheme`).
- **PWA**: 홈 화면 추가 배너(`beforeinstallprompt` → `installApp`), 오프라인 앱 셸 캐시(`sw.js`). 펫캠 dock 토글(`toggleDockHidden`).
- **접근성(A11y)**: `a11yDecorate`(+MutationObserver)가 재렌더 시 role/포커스/라벨을 자동 보강, 전역 키보드 핸들러(Enter/Space·Esc·포커스 트랩).
- **토스트 알림**: 모든 사용자 동작 피드백(`toast`).
- **🔔 푸시 알림(FCM, 서버리스)**: 설정 → 알림 토글로 켜면 **리마인더 푸시**(오늘 미기록 넛지 등)를 받음. 발송은 **GitHub Actions 스케줄 크론**(Blaze 불필요) + FCM. 토큰 `users/{uid}/push`, 클라 `js/push.js`+`firebase-messaging-sw.js`. iOS는 홈화면 설치 PWA(16.4+)에서만 동작. 설정·활성화는 [docs/deploy/push.md](deploy/push.md).
- **온보딩**: 첫 사용자 진입 시 **3스텝 안내 시트**(기록·친구·알뜰홈, `maybeOnboard`/`openOnboarding`, `users/{uid}/onboarded` 1회 멱등, 스킵 가능).

> ✅ 로드맵 기능이 모두 구현되었습니다(가계부 정산·경조사비·대출·권한/공동 설정 + 할일 개인/그룹·공유). 더보기 메뉴에 남은 "예정" 항목 없음.
