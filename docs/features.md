# 🧩 기능 카탈로그 (개요)

알뜰이 제공하는 기능의 **개요·인덱스**입니다. 앱은 **두 모드**로 나뉘며, 상세는 모드별 문서를 보세요. 데이터 구조는 [data-model.md](data-model.md), 함수 위치는 [code-structure.md](code-structure.md) 참고.

| 모드 | 무엇 | 상세 문서 |
|---|---|---|
| 💰 **가계부** | 개인·그룹 공유 가계부(거래·자산·카드실적·예산·구독·목적별·정산·경조사비·대출) | [features-ledger.md](features-ledger.md) |
| ✅ **할일** | 개인/그룹 공유 할일(프로필별 관리·친구 공유·담당 배정·반복·여행 연동) | [features-todo.md](features-todo.md) |

## 모드 전환 / 화면 구성

- **상단바**: **모드 토글**(`[가계부 | 할일]`, `setMode` — `localStorage('mode')` 유지), **워크스페이스 칩**(현재 가계부 전환), **펫캠 토글**, **테마 토글**(🌙/☀️). 상단바 아래엔 **알뜰홈 dock**(걸어다니는 도트 고양이 + 은화)이 상시 노출됩니다.
- **하단 탭바**는 모드별로 바뀝니다(`renderTabBar` / `_TABSETS`). 가운데 **＋** FAB는 모드에 따라 거래 추가/할일 추가로 분기(`fabAdd`). **더보기**는 두 모드 공용 진입점이지만 모드에 맞는 메뉴를 보여줍니다(`renderMore` 분기).
- **오늘 홈(랜딩)**: 상단 **로고=홈 버튼**(`goHome`)으로 진입하는 오늘 대시보드(오늘 미션·할일·지출 한 줄). 모드 화면에 있을 때 **오늘 미처리가 있으면 로고에 작은 점 배지**로 알려 순회 부담을 줄이고, 다 처리하면 **완료 카드**(고양이 + 1회 축하 연출, `prefers-reduced-motion` 정적)로 끝맺음을 줍니다. 남은 일 계산은 단일 순수 헬퍼 `todayPending`(util.js).

## 💰 가계부 모드 (요약)

개인·그룹이 함께 쓰는 공유 가계부. **거래 9종**(수입/지출/이체/충전/선불결제/환불/포인트±/잔액조정)을 기록하고, 달력·리포트로 보고, 자산·카드실적·예산·정기결제·구독·목적별 가계부·정산·경조사비·대출·적금을 관리합니다. **소비 대상(개인/공동) 분리 집계**, **해외통화(여행) 실시간 환율**, **CSV 내보내기** 지원.

→ 전체 내용은 **[features-ledger.md](features-ledger.md)**.

## ✅ 할일 모드 (요약)

개인이 **프로필별로 할일**(user-global — 워크스페이스와 무관하게 항상 동일, `users/{uid}/todos`)을 관리하고, **친구 코드로 친구를 맺어** '할일 공개'를 켠 친구의 할일을 읽기전용으로 봅니다. **그룹 할일**로 여행·모임의 담당을 나눕니다. 할일 화면 상단 **[개인 | 그룹] 세그먼트**(개인 워크스페이스에선 둘째 탭이 **'친구들'** 허브)로 전환하고, **친구들 피드**(공개 친구 아바타·오늘 무지개 테두리·친구 할일 목록, 친구 관리는 더보기 공용)·마감 캘린더·반복·목적별(여행) 연결·완료 시 **은화 보상**을 제공합니다.

→ 전체 내용은 **[features-todo.md](features-todo.md)**.

## 🐱 알뜰홈 (은화 경제 — 게임화)

가계부·할일 활동으로 **은화**를 모아 **고양이**를 입양·구경하는 게임화 기능. 소속은 **개인 전역**(`users/{uid}/game`)이라 개인↔그룹을 오가도 내 고양이/은화가 따라옵니다. 자세한 기획은 [cat-feature-plan.md](cat-feature-plan.md).

- **은화 미션**: 일일 미션(오늘 1건 추가 — 가계부 거래·할일 중 아무거나 1건 등록 시 +5 / 출석 +2)을 KST 자정 기준으로 판정, **멱등 수령**(같은 날 중복 지급 불가). 출석은 진입 시 자동 수령. **업적**(1회성): 첫 거래·고양이 3마리·여행 가계부·해외통화 첫 지출·첫 예산·첫 정산·**첫 할일 완료·할일 10개 완료** 등 앱 기능을 써보면 은화 지급(`ACHIEVEMENTS`, period `once`로 영구 저장). **내 미션(커스텀 습관)**: 미션 탭 '내 미션' 섹션에서 직접 추가(`openCustomMissionEdit`), **매일 체크는 무보상**·**7일 연속마다 +15 은화**(최대 5개, 개인 전역 `game/customMissions`·`game/missionLogs`, 날짜키 멱등·재지급 없음, 주간 리셋 없이 영구 지속), 🔥연속·최근7일 점 표시. 업적에 '첫 내 미션'·'7일 연속'도 포함. **매일 반복 습관은 내 미션**, **정해진 날짜 반복(매주·매월)은 할일 → 반복**으로 역할 분리(겹침 제거).
- **도트(픽셀) 아트**: 고양이(고등어·치즈·삼색 코숏)·은화·가구를 문자 매트릭스→SVG로 렌더(다크모드 자동 대응). **동물 <!--@gen:cats-full-->21종 전부(고등어·치즈·삼색·까망·하양·복슬이·턱시도·카오스·샴·황토·폴드·보라·초코·아깽이·스핑크스·고랑이·갈기냥·펠시안·백호·러시안블루·벵갈)<!--@gen:end--> PixelLab PNG 스프라이트 시트(288×48 6프레임)로 CSS `steps()` 걷기**(`PET_SPRITES`/`catActorHTML`, 시트 없는 동물은 SVG 매트릭스로 폴백). **옆으로 이동할 땐 옆 걷기 시트만**(east 기준, 서쪽은 `scaleX(-1)`), **가만히 서 있거나 캣타워·방석 등에서 쉴 땐 정면(south) 정지 이미지**로 전환(정면으로 서 있는 시간을 길게). 걷기 애니메이션 주기는 이동 속도에 맞춰(`--wdur`/`walkDur`) 발이 바닥을 미끄러지지 않게(무빙워크 방지). 옆(east) 걷기 시트가 없는 export는 `frontWalk`로 **이동 중 east 정지스틸만 보여 정면 걷기를 방지**(현재 14종 전부 east 옆걷기 보유 — 해당 없음). 새 동물 zip 처리 규칙은 [pet-asset-pipeline.md](pet-asset-pipeline.md).
- **펫별 크기 배율(`scale`)**: 종별 몸집을 반영(고양이=1.0 기준, 예 호랑이 5·곰 4·강아지 1.5·토끼 0.8·거북이 0.9·새 0.6). `PET_SPRITES[id].scale`(`tools/pets.json`의 `scale`에서 생성)을 `petScale()`이 읽어, **걷는 무대(웹캠 dock 방·알뜰홈 홈 방)에서 렌더 높이=기준×scale**로 반영(무대 밖으로 안 나가게 상한 클램프 — dock 96px·홈 200px). 알뜰샵/보유칩/뽑기 썸네일은 초상 프레임이라 균일.
- **전역 dock**: 모든 화면 상단에 얇은 스트립으로 은화 잔액 + 걸어다니는 고양이. `prefers-reduced-motion`·백그라운드 시 애니메이션 정지. **캠/방에서 펫을 바로 끌어(드래그) 좌우로 이동**할 수 있음(꾹 누를 필요 없이 살짝만 끌면 집힘, 놓으면 그 자리에서 다시 배회, `petGrabDown`). 드래그 중 이미지/텍스트 선택은 방지(`user-select:none`+preventDefault). **알뜰홈은 dock 좌상단 은화 배지를 탭**해 열며(누르는 press 애니메이션 후 열림, `coinTap`), 캠 빈 곳 탭은 아무 동작도 하지 않음.
- **알뜰홈 시트**(더보기 → 알뜰홈, 아이콘=은화): **홈**(방 뷰 + 걷는 고양이 + 배치 가구, 보유 고양이 탭해 집에 내보내기 — **활성 슬롯 기본 3 + 잠금 4번째 슬롯을 금화 100으로 확장**) / **알뜰샵**(고양이·가구·**소비**(사료·물)·벽지·이벤트 탭, 가구 수량 허용 — **고양이 카드를 탭하면 선택**되어 강조되고 썸네일이 옆으로 걷는 스프라이트로 미리보기됨 — 이름 오른쪽 분류 태그는 **품종이 아니라 종(species) 라벨**(고양이/강아지/토끼, `SPECIES_LABEL`)) / **배치**(12×12 격자, 캣타워=3×6·스크래처=2×2·화장실=2×1·펫하우스=3×3칸 점유·겹침 방지, **꾹 눌러(롱프레스) 드래그로 배치·이동**(화면 스크롤과 겹치지 않도록) — 짧게 탭하면 팔레트=선택·배치된 가구=회수/판매 메뉴) / **미션**(일일+주간+**업적**).
- **활성 슬롯 확장**: 집에 내보낼 수 있는 슬롯이 기본 3칸. 홈 상단 슬롯 행 오른쪽의 **잠금 슬롯(🔒 금화 100 표기)** 을 탭하면 **금화 100**으로 4번째 슬롯을 영구 확장(`home.slots` 3→4, `buySlot`/`slotCount`, 금화의 첫 소비처, 최대 20). dock·방 렌더와 내보내기 상한이 모두 **현재 방의** 슬롯 수를 따름.
- **여러 방(프리셋)**: 알뜰홈을 **여러 개의 방**으로 관리(게임 프리셋 방식). 방마다 **가구 배치·벽지·펫이 독립 저장**되고, 홈/배치 탭 상단의 **미니 미리보기 썸네일**(벽지+가구 축소·펫수·이름)을 탭해 전환한다. 기본 1개, 오른쪽 **잠금 방(🔒 금화 500)** 을 탭하면 **금화 500**으로 확장(**최대 5개**, `home.rooms[]`·`roomSlots`·`current`, `buyRoom`/`roomCount`/`switchRoom`). 썸네일 ✎는 **방 관리 시트**(`openRoomMenu`): 이름 변경 + 다른 방 **벽지 가져오기**(`copyRoomWall`) + **방 비우기**(`clearRoom` — 가구는 인벤토리로 돌아가 다른 방에 재배치, 펫은 대기). 캠(dock)·홈은 **현재 선택된 방**을 보여주고(방 여러 개면 dock에 방 이름), **친구·랭킹 방문은 지정한 대표 방(`showRoom`)만** 노출(사적인 방은 **DB 레벨로 비공개** — 친구는 공개 스냅샷 `homeCam/{uid}`(대표 방만)를 읽고, `users/{uid}/game`(모든 방)은 규칙상 소유자만 읽음). 대표 방은 방 관리에서 ★ 지정·썸네일 ★ 배지. 방마다 **이모지**(`setRoomEmoji`) 지정 가능. **한 펫은 한 방에만** 있고(다른 방에서 탭하면 그 방으로 이동, `toggleActiveCat` 트랜잭션), 펫 카드에 **현재 방 배지**·상태(이 방/○○방/대기)가 표기돼 방 전환 시 즉시 바뀜. 방 **순서 변경**(썸네일 롱프레스 드래그 `moveRoomTo`, 키보드용 ← → 버튼도 제공). 가구 인벤토리는 전역이라 **모든 방 배치 합**으로 소진(복제 불가, `sumPlacedItem`/`itemPlacedAll`); 밥·물그릇 정산은 **안 보는 방도** 3시간 뒤 처리. (레거시 단일 방 데이터는 첫 로드 시 방 1로 자동 이관 — `util.js normalizeHome`.)
- **주간 미션**: 5일 이상 기록(+20)·리포트 확인(+10), KST 월요일 초기화·멱등.
- **dock**: 얇은 스트립(탭 시 알뜰홈) ↔ 숨김(더보기 설정에서 토글).
- **동물 <!--@gen:cats-short-->21종(고등어·치즈·삼색·까망·하양·복슬이·턱시도·카오스·샴·황토·폴드·보라·초코·아깽이·스핑크스·고랑이·갈기냥·펠시안·백호·러시안블루·벵갈)<!--@gen:end-->**, **가구 8종**(방석·밥그릇·물그릇·캣타워·스크래처·화장실·펫하우스·화분), **벽지 10종**(기본·하늘·벚꽃·민트·별밤·살구·노을·숲·바다·라벤더, 알뜰샵 벽지 탭에서 구매·적용). 고양이 알뜰샵 가격(은화)은 **등급·확률에 맞춰 산정**(일반50·고급100·희귀200·특별400·전설800·한정1500, `TIER_PRICE`가 `CAT_TIER` 단일 소스로 자동 산정 — 알 100은화+금화·환급 대비 흔한 등급은 싸게·희귀는 비싸게). 상단 dock은 **웹캠 방**(위에서 아래로 내려다보는 뷰, 바닥 넓게·벽지 좁게)으로 벽지 배경 + 배치 가구(배경) + 걷는 고양이를 함께 보여주며, **LIVE 배지는 좌측 상단**. 가구는 **원근**을 적용해 앞(격자 **아랫줄**)일수록 크고 아래, 뒤(격자 **윗줄**)일수록 작고 위로 보이며 앞 가구가 뒤 가구를 가림. **배치 탭**엔 현재 배치를 실제 방으로 보여주는 **미니 웹캠 프리뷰**가 있어 방향을 확인할 수 있음(격자 위=방 뒤, 아래=방 앞).
- 고양이는 걷기 외에 **앉기·식빵·낮잠 포즈**(SVG 고양이) 또는 **멈춰 앞/뒤/좌/우 보며 쉬기**(스프라이트 고양이), 개별적으로 속도·방향·유휴가 랜덤이라 제각기 움직이며, 배치된 **가구로 다가가 종류별로 반응하며 몇 초간 머무름**(캣타워=3층 중 한 층에 올라가 정면 보며 쉼·방석=위에 잠시 올라감·밥그릇=뒤에서 앉아 먹음·스크래처=옆에서 머무름·**펫하우스=출입구 안에 들어가 정면 보며 아늑하게 오래 쉼**). 자유 로밍 펫끼리 같은 배치칸이 겹치면 비켜가고(`separatePets`), **가구로 가는(goal)·앉은(pause) 펫은 겹침분리에서 제외**돼 다른 펫에 막히지 않고 곧장 앉습니다.
- **펫 원근(캠/방)**: 고양이도 가구처럼 **좌우뿐 아니라 앞뒤(깊이)로도 이동**해 **가까우면 크고 앞으로, 멀면 작고 뒤로** 보임(근거리 확대는 넉넉히·원거리 축소는 적당히). 깊이 z-index가 가구와 같은 척도라 **가구를 가리기도·가려지기도** 함. 가구 상호작용 시엔 그 가구의 깊이에 맞춰 서고, **펫을 세로로 드래그하면 앞뒤로 이동**(위=멀리·작게, 아래=가까이·크게), 가로 드래그는 좌우 이동. (`cats.js` `applyDepth`/`depthScale`/`petScale`, `PET_NEAR_SCALE`/`PET_FAR_SCALE`.)
- **🍚 다마고치 사료·물·배변 루프**: 알뜰샵 **소비 탭**에서 **사료·물**(각 1 은화, 배치 불가) 구매 → 홈 화면에서 **밥그릇·물그릇을 탭**하면 사료/물 1개를 써서 채워짐. 채운 지 **3시간 뒤 그릇이 비워지고**, 비운 그릇 하나당 **화장실에 똥 1개**가 쌓임. **똥을 탭하면 +2 은화**. 홈·캠 **우측 상단 "돌보기" 버튼**으로 **일괄 처리**(모든 그릇 채우고 똥 모두 치우기). 밥·물그릇·화장실은 **고양이 최대 마릿수만큼만 배치** 가능.
- **고양이 이름 짓기**: 홈 "우리집 펫" 칩의 **✎ 버튼**으로 고양이별 이름을 지을 수 있음(최대 12자, `owned.cats[id].name`). 지은 이름도 **등급 색**(한정=무지개)으로 표기됨.
- **개발자 모드 진입**: 개발자 이메일(`isDev`) 계정은 **더보기 그리드에 무지개알 '개발자' 타일**이 노출되고, 탭하면 **개발자 모드 시트**(`openDevModeSheet`)에서 켜기/끄기 + 펫알·박스 확률 설정 + 펫 관리로 진입(설정 시트에는 더 이상 없음).
- **개발자 펫 관리(앱 내)**: 개발자 모드에서 **펫 (추가·수정·삭제)** — 전체 펫 목록에서 골라 관리한다. **추가**=PixelLab zip 업로드로 새 펫 등록, **수정**=이름·분류·등급·크기 변경 + zip 재업로드 시 디자인 교체(정적 펫도 오버라이드), **삭제**=소프트 삭제(이미지·정의 보존, 알뜰샵/가챠/목록에서만 숨김 · 관리 화면엔 회색 "삭제됨"), 삭제된 펫은 **복구**로 재활성화. 앱에서 바로 처리(JSZip+canvas)해 RTDB `catalogPets` 전역 저장 → 모든 사용자 반영(재배포 불필요). 쓰기는 개발자 이메일만(RTDB 규칙). 정적 파이프라인은 공식 펫용으로 병행.
- **프로모 코드**: 더보기 → 코드 입력. 각 코드는 1회 제한이지만 **앞에 `@`를 붙이면 무제한** 사용(개발자·테스트용).
- **코드 입력**(더보기 → 설정): `showmethemoney`(999 은화)·`helloeggarden`(무지개알 1)·`eggardentodo`(무지개박스 1)·`eggmoneyna`(펫알 10). 보상은 곧바로 지급되지 않고 **선물함**으로 적립되며, **일반 사용자는 코드당 1회·개발자 계정(`isDev`)은 무제한**(`PROMO_CODES`).
- **🎁 선물함 · 🎒 가방**(더보기 그리드): 코드 보상은 **선물함**(랜덤박스 도트를 선물상자 색으로 재채색한 `giftSvg` 아이콘)에 쌓이고, **받기/모두 받기** 하면 은화는 잔액으로·아이템은 **가방**으로 이동. **가방**에서 보유한 **펫알·랜덤박스**(일반 확률)·**무지개알·무지개박스**(특별↑)를 **사용**해 오픈(`consum.egg/box/rainbow_egg/rainbow_box`, `game.gifts`). 선물함 행은 아이콘·이름과 함께 **메시지**(`gift.msg`)도 표시.
- **🎉 회원가입 축하 선물**: 신규 계정 첫 진입 시 **은화 100 + 펫알 1개**를 선물함에 넣고 "알뜰 회원가입을 축하 선물이에요! 🎉" 메시지를 남김(`grantWelcomeGift`, `users/{uid}/welcomeGift` 플래그로 1회 멱등).
- **🏆 랭킹(집 좋아요 TOP10)**: 더보기 **트로피 타일** → `openRanking`. 전체 사용자 중 집(펫캠) **좋아요 수** 상위 10 — **1·2·3등 금·은·동 메달 단상**, 4~10등 리스트(아바타·닉네임·❤수). 항목 탭=그 사람 **캠만** 방문(할일은 친구 사이일 때만). 공용 경량 노드 `rankings/{uid}`(소유자만 유지·`writeMyRanking`)만 읽어 정렬, 상위권 사진만 지연 로드. **비공개 프로필**은 은화+'알뜰'로 익명 등장.
- **이벤트(뽑기)**: 알뜰샵 이벤트 탭에서 **펫알**(→고양이)·**랜덤박스**(→가구) 각 100 은화. 구매 시 화면 중앙 오픈 연출 → 등급(일반/고급/희귀/특별/전설/한정, 확률 60/20/15/3.8/1/0.2%) 랜덤 보상. 하단 **접이식 `📋 구성·확률 보기`** 로 등급별 구성·확률 확인. **알뜰샵 고양이·가구는 등급 오름차순 정렬**이며, **특별(epic) 이상은 은화 구매 불가 → 펫은 `🥚 펫알 전용`·가구는 `🎁 랜덤박스 전용`(가챠로만)**. 열 때마다 **금화 1개**, 중복 고양이는 **그 펫 가격의 20% 은화** 환급. **✨ 무지개알·무지개박스**(이벤트 탭, **각 금화 100**)는 사용 시 **특별70·전설20·한정10%** 확정. **오픈 연출은 등급색 기반 픽셀아트**로 개편 — 무대 전체가 등급색으로 틴트되어 파티클·광선·반짝임·프레임이 등급색을 따르고 **등급↑일수록 화려**, 무지개는 열기 전 **무지갯빛 반짝임**. 알이 갈라지는/박스가 열리는 순간의 빛은 **화려한 도트 방사 버스트(십자 아닌 12갈래)+은은한 디더 오오라**가 **바깥으로 살짝씩 퍼져나가는(발산)** 연출(회전 아님), 열고 나면 **펫 주변에 작고 은은한 오오라 + 둘레 트윙클 반짝임**(화면 정중앙 아님, 펫을 따라감).

## 공통 기반

두 모드가 함께 쓰는 토대입니다.

- **로그인 · 인증**: 이메일/비밀번호(Firebase Auth). 로그인 화면 하단에 **아이디 저장 · 자동 로그인** 흰검 토글(`localStorage` 저장·로그아웃 후에도 유지, 기본 on). 자동 로그인 on=`LOCAL` 지속성(앱 재실행에도 로그인 유지)·off=`SESSION`(완전 종료 시 재로그인), 아이디 저장 on이면 이메일 자동 입력(`authOptGet`/`beforeAuth`). **아이디 · 비밀번호 찾기**: 로그인 화면 링크 → **로그인 도움 시트**(`openLoginHelpSheet`) — 아이디는 곧 가입 이메일이라 안내로 대체하고, 이메일을 넣어 **비밀번호 재설정 메일**(`sendPasswordReset` → `sendPasswordResetEmail`)을 받는다. (실제 발송엔 Firebase Console 승인 도메인·재설정 이메일 템플릿 설정 필요.)
- **워크스페이스(개인/그룹)**: 모든 데이터(`ws/{wsId}`)와 멤버·초대코드의 격리 단위. 개인 가계부는 가입 시 자동 생성, 그룹은 6자리 초대코드로 합류(`joinByCode`)·공동 read/write. 전환 `switchWorkspace`. 상세는 [features-ledger.md](features-ledger.md#워크스페이스-개인--그룹-공유).
- **프로필(사진/이름/비밀번호/공개)**: 더보기 프로필 줄 → **내 프로필**(`openProfileSheet`) — 사진 설정/삭제 + 별명 수정 + **계정 이메일(아이디) 표시** + **비밀번호 변경** + **프로필 공개/비공개 토글**(`users/{uid}/profilePublic`; 비공개면 랭킹·비친구에게 **은화+'알뜰'** 익명). 사진은 **256px JPEG base64**(`users/{uid}/photo`). 이름은 내가 속한 모든 워크스페이스 멤버 이름에 반영. **사진 없는 기본 아바타=은화 픽셀 아이콘**(개인, `avatarHtml`), **그룹/가계부 기본=금화**(`wsAvatarHtml`). 멤버 사진은 `loadMemberPhotos`로 캐시.
- **가계부(워크스페이스) 프로필**: 그룹 이름·사진 편집(`openWsProfileSheet`, `wsAvatarHtml`).
- **다크모드**: 토글(localStorage 저장, `applyTheme`/`toggleTheme`).
- **PWA**: 홈 화면 추가 배너(`beforeinstallprompt` → `installApp`), 오프라인 앱 셸 캐시(`sw.js`). 펫캠 dock 토글(`toggleDockHidden`).
- **접근성(A11y)**: `a11yDecorate`(+MutationObserver)가 재렌더 시 role/포커스/라벨을 자동 보강, 전역 키보드 핸들러(Enter/Space·Esc·포커스 트랩).
- **토스트 알림**: 모든 사용자 동작 피드백(`toast`).

> ✅ 로드맵 기능이 모두 구현되었습니다(가계부 정산·경조사비·대출·권한/공동 설정 + 할일 개인/그룹·공유). 더보기 메뉴에 남은 "예정" 항목 없음.
