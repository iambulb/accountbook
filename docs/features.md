# 🧩 기능 카탈로그

공유 가계부 앱이 제공하는 기능을 화면·시트 단위로 정리합니다. 데이터 구조는 [data-model.md](data-model.md), 함수 위치는 [code-structure.md](code-structure.md) 참고.

## 화면 구성 — 하단 4탭 + 거래추가 FAB

`index.html` 하단 탭바 기준.

| 탭 | 아이콘 | 화면 | 주요 함수 |
|---|---|---|---|
| 달력 | 📅 | 월 네비게이션 + 요약 + 달력 그리드(일별 수입/지출) / 거래내역 리스트 | `renderCalendar` |
| 리포트 | 📊 | 월 요약·카테고리 도넛차트·6개월 추이·**개인별/공동 지출 분리**·**통화별 지출**(해외통화 있을 때)·**전월비 급증 인사이트**·예산 임계 경고 | `renderStats` |
| (가운데) **＋** | ➕ | 거래 추가/편집 시트 | `openTxSheet` |
| 자산 | 🏦 | 결제수단 목록·잔액·카드 실적·선불/포인트 요약·적금 목표 | `renderAssets` |

상단바에는 **워크스페이스 칩**(현재 가계부 전환), **테마 토글**(🌙/☀️)이 있습니다. 상단바 아래에는 **알뜰샵 dock**(걸어다니는 도트 고양이 + 은화, 탭 시 알뜰샵)이 상시 노출됩니다.

## 🐱 알뜰샵 (은화 경제 — 게임화)

가계부 활동으로 **은화**를 모아 **고양이**를 입양·구경하는 게임화 기능. 소속은 **개인 전역**(`users/{uid}/game`)이라 개인↔그룹 가계부를 오가도 내 고양이/은화가 따라옵니다. 자세한 기획은 [cat-feature-plan.md](cat-feature-plan.md).

- **은화 미션**: 일일 미션(오늘 거래 1건 기록 +5 / 출석 +2)을 KST 자정 기준으로 판정, **멱등 수령**(같은 날 중복 지급 불가). 출석은 진입 시 자동 수령. **업적**(1회성): 첫 거래·고양이 3마리·여행 가계부·해외통화 첫 지출·첫 예산·첫 정산 등 앱 기능을 써보면 은화 지급(`ACHIEVEMENTS`, period `once`로 영구 저장).
- **도트(픽셀) 아트**: 고양이(고등어·치즈·삼색 코숏)·은화·가구를 문자 매트릭스→SVG로 렌더(다크모드 자동 대응). **고양이 <!--@gen:cats-full-->15종 전부(고등어·치즈·삼색·까망·하양·복슬이·턱시도·카오스·샴·벵갈·폴드·보라·초코·아깽이·스핑크스)<!--@gen:end--> PixelLab PNG 스프라이트 시트(288×48 6프레임)로 CSS `steps()` 걷기**(`PET_SPRITES`/`catActorHTML`, 시트 없는 동물은 SVG 매트릭스로 폴백). **옆으로 이동할 땐 옆 걷기 시트만**(east 기준, 서쪽은 `scaleX(-1)`), **가만히 서 있거나 캣타워·방석 등에서 쉴 땐 정면(south) 정지 이미지**로 전환(정면으로 서 있는 시간을 길게). 걷기 애니메이션 주기는 이동 속도에 맞춰(`--wdur`/`walkDur`) 발이 바닥을 미끄러지지 않게(무빙워크 방지). 옆(east) 걷기 시트가 없는 export는 `frontWalk`로 **이동 중 east 정지스틸만 보여 정면 걷기를 방지**(현재 14종 전부 east 옆걷기 보유 — 해당 없음). 새 동물 zip 처리 규칙은 [pet-asset-pipeline.md](pet-asset-pipeline.md).
- **펫별 크기 배율(`scale`)**: 종별 몸집을 반영(고양이=1.0 기준, 예 호랑이 5·곰 4·강아지 1.5·토끼 0.8·거북이 0.9·새 0.6). `PET_SPRITES[id].scale`(`tools/pets.json`의 `scale`에서 생성)을 `petScale()`이 읽어, **걷는 무대(웹캠 dock 방·알뜰샵 홈 방)에서 렌더 높이=기준×scale**로 반영(무대 밖으로 안 나가게 상한 클램프 — dock 96px·홈 200px). 상점/보유칩/뽑기 썸네일은 초상 프레임이라 균일.
- **전역 dock**: 모든 화면 상단에 얇은 스트립으로 은화 잔액 + 걸어다니는 고양이. `prefers-reduced-motion`·백그라운드 시 애니메이션 정지.
- **알뜰샵 시트**(더보기 → 알뜰샵, 아이콘=은화): **홈**(방 뷰 + 걷는 고양이 + 배치 가구, 보유 고양이 탭해 집에 내보내기 — **활성 슬롯 기본 3 + 잠금 4번째 슬롯을 금화 100으로 확장**) / **상점**(고양이·가구·**소비**(사료·물)·벽지·이벤트 탭, 가구 수량 허용 — **고양이 카드를 탭하면 선택**되어 강조되고 썸네일이 옆으로 걷는 스프라이트로 미리보기됨 — 이름 오른쪽 분류 태그는 **품종이 아니라 종(species) 라벨**(고양이/강아지/토끼, `SPECIES_LABEL`)) / **배치**(12×12 격자, 캣타워=3×6·스크래처=2×2·화장실=2×1·펫하우스=3×3칸 점유·겹침 방지, **꾹 눌러(롱프레스) 드래그로 배치·이동**(화면 스크롤과 겹치지 않도록) — 짧게 탭하면 팔레트=선택·배치된 가구=회수/판매 메뉴) / **미션**(일일+주간+**업적**).
- **활성 슬롯 확장**: 집에 내보낼 수 있는 슬롯이 기본 3칸. 홈 상단 슬롯 행 오른쪽의 **잠금 슬롯(🔒 금화 100 표기)** 을 탭하면 **금화 100**으로 4번째 슬롯을 영구 확장(`home.slots` 3→4, `buySlot`/`slotCount`, 금화의 첫 소비처). dock·방 렌더와 내보내기 상한이 모두 슬롯 수를 따름.
- **주간 미션**: 5일 이상 기록(+20)·리포트 확인(+10), KST 월요일 초기화·멱등.
- **dock**: 얇은 스트립(탭 시 알뜰샵) ↔ 숨김(더보기 설정에서 토글).
- **고양이 <!--@gen:cats-short-->15종(고등어·치즈·삼색·까망·하양·복슬이·턱시도·카오스·샴·벵갈·폴드·보라·초코·아깽이·스핑크스)<!--@gen:end-->**, **가구 8종**(방석·밥그릇·물그릇·캣타워·스크래처·화장실·펫하우스·화분), **벽지 10종**(기본·하늘·벚꽃·민트·별밤·살구·노을·숲·바다·라벤더, 상점 벽지 탭에서 구매·적용). 고양이 상점 가격(은화)은 **등급·확률에 맞춰 산정**(일반50·고급100·희귀200·특별400·전설800·한정1500, `TIER_PRICE`가 `CAT_TIER` 단일 소스로 자동 산정 — 알 100은화+금화·환급 대비 흔한 등급은 싸게·희귀는 비싸게). 상단 dock은 **웹캠 방**(위에서 아래로 내려다보는 뷰, 바닥 넓게·벽지 좁게)으로 벽지 배경 + 배치 가구(배경) + 걷는 고양이를 함께 보여주며, **LIVE 배지는 좌측 상단**. 가구는 **원근**을 적용해 앞(격자 **아랫줄**)일수록 크고 아래, 뒤(격자 **윗줄**)일수록 작고 위로 보이며 앞 가구가 뒤 가구를 가림. **배치 탭**엔 현재 배치를 실제 방으로 보여주는 **미니 웹캠 프리뷰**가 있어 방향을 확인할 수 있음(격자 위=방 뒤, 아래=방 앞).
- 고양이는 걷기 외에 **앉기·식빵·낮잠 포즈**(SVG 고양이) 또는 **멈춰 앞/뒤/좌/우 보며 쉬기**(스프라이트 고양이), 개별적으로 속도·방향·유휴가 랜덤이라 제각기 움직이며, 배치된 **가구로 다가가 종류별로 반응하며 몇 초간 머무름**(캣타워=3층 중 한 층에 올라가 정면 보며 쉼·방석=위에 잠시 올라감·밥그릇=뒤에서 앉아 먹음·스크래처=옆에서 머무름·**펫하우스=출입구 안에 들어가 정면 보며 아늑하게 오래 쉼**).
- **🍚 다마고치 사료·물·배변 루프**: 상점 **소비 탭**에서 **사료·물**(각 1 은화, 배치 불가) 구매 → 홈 화면에서 **밥그릇·물그릇을 탭**하면 사료/물 1개를 써서 채워짐(이미지로도 밥·물이 채워짐). 채운 지 **3시간 뒤 그릇이 비워지고**, 비운 그릇 하나당 **화장실(펫 화장실)에 똥 1개**가 쌓임. **똥을 탭하면 +2 은화**(작은 획득 연출). 앱을 가끔 열어 상호작용하며 은화를 버는 컨셉. (밥그릇 기본 이미지는 빈 그릇) 홈·캠 **우측 상단 "돌보기" 버튼**으로 **일괄 처리**(모든 그릇 채우고 똥 모두 치우기) — 은화가 카운터로 날아드는 연출. 밥·물그릇·화장실은 **고양이 최대 마릿수만큼만 배치** 가능.
- **고양이 이름 짓기**: 홈 "우리집 펫" 칩의 **✎ 버튼**으로 고양이별 이름을 지을 수 있음(최대 12자, `owned.cats[id].name`). 지은 이름도 **등급 색**(한정=무지개)으로 표기됨.
- **코드 입력**(더보기 → 설정): `showmethemoney` 입력 시 999 은화(사용자별 1회).
- **이벤트(뽑기)**: 상점 이벤트 탭에서 **펫알**(→고양이)·**랜덤박스**(→가구) 각 100 은화. 펫알·랜덤박스 아트는 **무지개 물음표**가 그려진 달걀/상자 도트. 구매 시 화면 중앙 오픈 연출(펫알 3탭 균열, 랜덤박스 화려 오픈) → 등급(일반/고급/희귀/특별/전설/한정, 확률 60/20/15/3.8/1/0.2%) 랜덤 보상. 이벤트 탭 하단의 **접이식 `📋 구성·확률 보기`** 로 펫알·랜덤박스의 **등급별 구성 목록과 확률**을 확인. **상점 고양이는 등급 오름차순 정렬**이며, **특별(epic) 이상은 상점 은화 구매 불가 → `🥚 펫알 전용` 표기(가챠로만 획득)**. 오픈 절정에서 **껍질 조각이 튀어 옆에 흩어지고**, 껍질 사이로 새어나오는 빛은 **등급색·등급이 높을수록 강하게**(한정=무지개), 특별↑은 검은 고양이 앞발이 톡 건드림. 열 때마다 **금화 1개**, 중복 고양이는 **그 펫 가격의 20% 은화** 환급(가구 박스는 중복 없이 수량 누적).

## 거래 (Transactions)

추가/수정/삭제 가능하며 9종 타입을 지원합니다. 각 타입은 잔액에 미치는 효과(`from`에서 차감 / `to`에 가산)가 다릅니다 — 정의는 `public/js/constants.js` 의 `TX_EFFECT`.

| 타입 | 라벨 | 아이콘 | 잔액효과 | 통계(실소비) |
|---|---|---|---|---|
| `income` | 수입 | 💰 | to에 가산 | |
| `expense` | 지출 | 💳 | from에서 차감 | ✅ 기본 포함 |
| `transfer` | 이체 | 🔄 | from 차감 + to 가산 | |
| `prepaid_charge` | 충전 | ⤴️ | from 차감 + to 가산 | |
| `prepaid_spend` | 선불결제 | 🛒 | from에서 차감 | ✅ 기본 포함 |
| `refund` | 환불 | ↩️ | to에 가산 | |
| `point_earn` | 포인트적립 | ⭐ | to에 가산 | |
| `point_spend` | 포인트사용 | ✨ | from에서 차감 | ✅ 기본 포함 |
| `balance_adjustment` | 잔액조정 | 🛠️ | to에 가산(음수 허용) | |

- **실소비 여부**(`isActualExpense`)는 거래별로 override 가능 — 리포트 통계 포함을 제어. 기본값은 `ACTUAL_DEFAULT`.
- 거래에는 카테고리·계좌(from/to)·날짜·설명·메모·**소비 대상(user)**·목적별 가계부 연결·카드실적 포함 여부 등이 붙습니다.
- **소비 대상 분리**: 지출/선불결제/포인트사용 거래는 **출금 수단(어느 계좌에서 나갔나)** 과 **소비 대상(누구의 소비인가)** 을 따로 고릅니다. 소비 대상은 워크스페이스 멤버 또는 **`공동`**(집세 등 공동 비용)으로 지정 — 정기거래에도 동일하게 적용. 리포트의 "개인별 지출/공동 지출"이 이 값으로 집계되어, **각자 용돈으로 쓴 금액**과 **공동 비용**을 나눠 볼 수 있습니다.
- **필터**: 타입(지출/수입/이체)·키워드 검색 칩으로 거래내역을 거릅니다.
- **이체 분류(곗돈 등)**: 이체 거래도 카테고리를 붙일 수 있음(기본 **곗돈**(🤝) 제공) — 계모임 납입·수령을 이체로 기록해 곗돈으로 분류. 이체는 실소비/예산 통계에 미포함이라 곗돈이 지출·수입을 왜곡하지 않음.
- **해외통화(여행용)**: 금액 입력 시 **통화 선택**(USD·JPY·EUR·CNY 등). 외화 선택 시 소수점 입력 가능하고 **환율(원화/1단위)을 입력**하면 원화로 환산돼 저장(`amount`=원화 환산액). 거래에 `currency`·`foreignAmount`·`fxRate`·`fxSource`·`fxDate` 저장, 목록엔 원화+외화 원금 병기. **실시간 환율 자동조회**(frankfurter, 무키·거래일자 반영·일자별 캐시)와 **직접 입력** 모두 지원(🔄로 재조회, 실패 시 수동 폴백).
- **CSV 내보내기**: 더보기 → 📤 (`exportCSV`). 해외통화 거래는 `원통화·외화금액·환율·환율원본·환율일자` 컬럼까지 내보내 원본 보존(왕복 가능).

## 워크스페이스 (개인 / 그룹 공유)

이 앱의 핵심 — 모든 가계부 데이터는 워크스페이스(`ws/{wsId}`) 단위로 격리됩니다.

- **개인 가계부**: `type:'personal'`, 멤버 1명. 가입 시 자동 생성(`createPersonalWorkspace`).
- **그룹 가계부**: `type:'group'` + **6자리 초대코드**. 코드를 아는 사람은 즉시 멤버로 합류(`joinByCode`). 그룹 안에서는 서로의 거래까지 공동으로 읽고 씁니다.
- **멤버 역할**: owner(👑) / member(👤). 멤버 목록·코드 공유는 그룹 관리 시트(`openGroupManageSheet`).
- **전환**: 상단 워크스페이스 칩 또는 더보기 → 가계부 전환(`switchWorkspace`).
- **나가기/정리**: 마지막 멤버가 나가면 워크스페이스·코드까지 삭제(`leaveWorkspace`).
- **v2→v3 자동 이전**: 구버전 전역 데이터가 있으면 로그인 시 "공유 가계부" 그룹으로 1회 이전(`migrateLegacyIfNeeded`).

## 결제수단 / 자산

- **계좌 타입**: 현금·은행계좌·신용카드·체크카드·선불충전금·포인트·간편결제·상품권·기타 (`ACCT_TYPES`).
- **제공사**: 직접·네이버페이·쿠팡·카카오페이·토스·기타 (`PROVIDERS`).
- **공개 범위**(`visibility`): 전체 공개 / 잔액만 공개 / 개인만 보기 (`VISIBILITY`). UI 단에서 필터링.
- **소유자**: 멤버 이름 또는 "공동".
- 초기 잔액·색상·메모, 잔액 자동 계산(거래 흐름 반영).
- **선불·포인트** 계좌는 자산 탭에서 별도 잔액 요약.

## 카드 실적 (신용/체크카드)

- 카드별 **월 실적 기준 금액**(`monthlyPerformanceTarget`).
- 실적 기간: 달력 월 / 사용자지정 시작일(`performancePeriodType`, `performanceStartDay`).
- 거래별 실적 포함 토글·금액·제외 사유, **실적 제외 카테고리**, **선불충전 실적 포함** 옵션.
- 자산 탭과 카드 실적 시트(`openCardList`)에서 진행률 시각화.

## 예산 (Budget)

- **총예산** 또는 **카테고리별 예산**.
- 기간: 주간/월간/연간/사용자지정 (`periodType`).
- 범위: 공동(group) / 개인(personal).
- 80% 등 임계치 경고(`alertEnabled`, `alertThreshold`).
- 진행률 막대 색상: 초록(0–80%)→노랑(80–90%)→주황(90–100%)→빨강(100%+) — `budgetColor`.
- 상세 보기에서 포함된 거래 확인(`openBudgetDetail`).

## 정기결제 / 반복거래 (Recurring)

- 주기: 매일/매주/매월/매년/사용자지정 + 간격(`interval`).
- 상태: active / paused / ended.
- **자동 생성**(`autoCreate`) — 로그인 시 도래한 반복거래를 자동 기록하며, `recurringLogs` 멱등 키로 중복 방지.
- 달력에 "다가오는 반복결제" 표시. 편집은 `openRecurringEdit`.
- 구버전 고정지출(`fixedExpenses`)은 반복거래로 자동 이전(`migrateFixed`).

## 구독 (Subscription)

- 유형: 영상·음악·쇼핑·클라우드·생산성·앱·멤버십·도메인/호스팅·금융·보험·기타 (`SUB_TYPES`).
- 청구주기: 매주/매월/매년/사용자지정. 상태: 구독중/일시정지/취소/만료.
- 체험기간(`isTrial`, `trialEndDate`), 다음 청구일, 만료일, 자동갱신.
- 월/연 환산 금액 계산, 7일 내 청구 예정 알림. 화면: `openSubscriptions`.

## 목적별 가계부 (Purpose Books)

- 유형: 여행·모임/계·데이트/부부·가족·프로젝트·동아리·이벤트·공동지출·기타 (`PB_TYPES`).
- 아이콘·이름·상태(진행중/완료/보관)·예산·기간(시작/종료).
- 참여자 목록(`participants`)·**정산 사용**(`settlementEnabled`) 플래그.
- 거래를 목적별 가계부에 연결. 리포트에서 사용 상위 3개 표시. 화면: `openPurposeBooks`. **여행 PB 상세엔 통화별 지출 요약**(외화 원금+원화 환산 병기, `sumByCurrency`) 표시.
- **기준 통화(여행)**: PB에 기준 통화를 지정(드롭다운)하면, 그 PB에 연결하는 거래의 **통화 기본값이 자동으로 그 통화**로 설정되고 실시간 환율까지 자동 채워짐(사용자가 직접 고른 통화는 존중).

## 공동 지출 정산 (Settlement)

목적별 가계부에서 **정산 사용**을 켠 경우, 그 안의 공동 지출을 정산할 수 있습니다.

- **거래 입력 시 정산**(선택 PB가 `settlementEnabled`일 때만 노출): 정산 포함 토글 → 결제자·분담 방식(균등 분할/직접 입력/결제자 부담)·참여자·참여자별 부담 금액·메모. 거래에 `payer`·`splitType`·`splitParticipants`·`splitAmounts`·`settlementStatus` 저장. 함수 `renderSettleBlock`/`collectSettle`.
- **정산 계산**(`pbSettleSummary`/`settlementSplit`/`greedySettle`): 참여자별 결제(paid)·부담(owed)·잔액(balance), 단순 최소 송금 제안(받을·보낼 순차 매칭).
- **목적별 상세 [정산] 탭**(`renderPbSettleTab`): 요약(총 공동지출·대상 건수·미정산/완료 금액·완료율), 참여자별 잔액, 송금 제안+완료 처리, 완료 내역+취소, 정산 대상 거래.
- **송금 완료**(`saveSettlementPayment`): `settlementPayments` 노드에 기록(기본은 상태만 관리). 옵션으로 실제 `transfer` 거래 동시 생성(실제소비 미포함).
- 목적별 카드·더보기 `정산` 메뉴(`openSettlementOverview`)에서 상태 요약.
- **중복 집계 방지**: 원본 결제 거래만 실제소비 1회 반영. 정산 송금은 `isActual`이 아니므로 통계·예산·리포트에 잡히지 않음.

## 경조사비 관리 (Gift / 경조사)

결혼·장례·돌·생일 등 경조사비를 주고받은 내역과 인맥을 관리합니다. 더보기 → 💐 경조사비(`openGiftBook`).

- **요약**: 보냄 합계·받음 합계·순(받음−보냄). 3탭 — 기록/예정/인맥.
- **기록**(`giftEvents`): 상대(이름)·관계(`REL_TYPES`)·경조사 유형(`GIFT_EVENT_TYPES`)·방향(줌=`given`/받음=`received`)·금액·날짜·메모. `openGiftEdit`/`saveGiftEvent`. 상대 이름은 **인맥 자동 등록·매칭**.
- **가계부 거래 연결**(기본 ON): 줌 → `경조사` 지출, 받음 → `경조사비 수령` 수입 거래를 생성하고 `giftEventId`로 연결(거래 행에 🎁 배지). 토글 OFF면 장부 기록만. → **줌(지출)은 실제소비 1회 반영, 장부와 중복 집계 없음**.
- **예정**(`plannedGiftEvents`): 다가올 경조사 등록(예상 금액·날짜·상태), `완료` 시 기록 입력 폼을 프리필. `openPlannedEdit`/`savePlanned`/`completePlanned`.
- **인맥**(`people`): 관계·메모, 인맥별 보냄/받음 합계. `openPersonEdit`/`savePerson`.

## 대출 / 이자 관리 (Loan)

빌린 돈(내 빚)과 빌려준 돈, 이자·상환을 관리합니다. 더보기 → 🏧 대출/이자(`openLoanBook`).

- **대출**(`loans`): 이름·방향(빌림 `borrowed`/빌려줌 `lent`)·상대/기관·원금·연이율(%)·시작/만기일·기본 상환계좌. `openLoanEdit`/`saveLoan`.
- **상세**(`openLoanDetail`): 잔액·원금·누적 이자·상환률 바, **월 예상 이자(잔액×연이율/12, 단리)**, 상태(상환중/완료/연체). 계산은 `loanCalc`.
- **상환 기록**(`loanPayments`): 원금 상환 + 이자 입력 → 잔액 자동 차감. `openLoanPayment`/`saveLoanPayment`.
- **거래 연결**(기본 ON): **원금·이자 모두** 실제 거래로 연결해 **선택 계좌 잔액에 반영**(따로 또 입력할 필요 없음) — 빌림 → `대출이자` 지출(실제소비)+`대출상환` 지출(원금, isActualExpense:false), 빌려줌 → `이자`·`원금회수` 수입. `loanId`로 연결(거래 행 🏦 배지), 이자=linkedTransactionId·원금=linkedPrincipalTxId. **원금은 부채 상환이라 실제소비/예산 통계엔 제외**(잔액만 반영) → 이중집계 없음.

## 적금 목표 (Savings)

- 이름·목표액·현재액, 진행률(%) 시각화. 사용자별 관리. 화면: `openSavingsSheet`.

## 권한 / 공동 설정 (Permissions / Shared)

더보기 → 🔒 권한/공동 설정(`openSharedSettings`).

- **멤버/권한 관리**(소유자 전용, 그룹): `openGroupManageSheet`에서 그룹 이름 변경(`renameWorkspace`)·소유자 이전(`transferOwnership`)·멤버 내보내기(`removeMember`). 워크스페이스 `role`(owner/member)을 실제로 활용. **권한은 앱 UI에서만 게이팅**(보안규칙은 그룹 멤버 공동권한 유지). 멤버 내보내기는 상대의 `ws/{wsId}` 접근을 차단(상대의 `users/ws` 인덱스는 본인만 삭제 가능).
- **공동 기본값**: 새 항목 기본 공개범위(전체/개인)·기본 소유자(공동/나)를 `ws/{wsId}/settings`에 저장. 생성 폼이 `defaultVisibility`/`defaultOwnerName`로 기본값 적용.
- **공개범위 개요**: 전 엔티티의 `visibility==='private'` 항목을 모아 보고 "공개로"·"전체 공개로 전환" 버튼으로 전환(`collectPrivateItems`·`makeItemPublic`·`makeAllPublic`).

## 프로필 (사진 / 이름)

- 더보기 프로필 줄 → **내 프로필**(`openProfileSheet`): 기기 사진으로 **프로필 사진 설정/삭제** + **별명(이름) 수정**.
- 사진은 브라우저 캔버스로 **256px JPEG 리사이즈 후 base64**로 `users/{uid}/photo`에 저장(Firebase Storage 미사용). 이름 변경은 내가 속한 모든 워크스페이스의 멤버 이름에 반영(비정규화).
- **그룹 멤버 프로필**: 그룹 관리 멤버 목록에 멤버 아바타 표시. 사진 없으면 이니셜 폴백(`avatarHtml`). 멤버 사진은 `loadMemberPhotos`로 캐시(`state.userPhotos`).
