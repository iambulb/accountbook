# 💰 가계부(Ledger) 모드 — 기능 상세

> 알뜰의 **두 모드 중 하나**입니다. 상단 **모드 토글(가계부 ↔ 할일)** 로 전환합니다. 전체 개요는 [features.md](features.md), 할일 모드는 [features-todo.md](features-todo.md), 데이터 구조는 [data-model.md](data-model.md), 함수 위치는 [code-structure.md](code-structure.md) 참고.

개인·그룹이 함께 쓰는 공유 가계부. 거래 기록부터 카드 실적·예산·구독·목적별 가계부·정산·경조사비·대출까지 지출 관리를 한 곳에서 합니다. 모든 데이터는 워크스페이스(`ws/{wsId}`) 단위로 격리됩니다(→ 워크스페이스는 [features.md](features.md#공통-기반) 공통 기반 참고).

## 화면 구성 — 하단 4탭 + 거래추가 FAB

가계부 모드 하단 탭바(`_TABSETS.ledger`).

| 탭 | 아이콘 | 화면 | 주요 함수 |
|---|---|---|---|
| 자산 | 🏦 | 결제수단 목록·잔액·카드 실적·선불/포인트 요약(**잔액 마이너스 시 자동충전**)·적금(만기·예상이자 자동 계산)·**주식(평가금액·손익·수익률 — 순자산 포함)** | `renderAssets` |
| 캘린더 | 📅 | 월 네비게이션 + 요약 + 달력 그리드(일별 수입/지출) / 거래내역 리스트 | `renderCalendar` |
| (가운데) **＋** | ➕ | 거래 추가/편집 시트 | `openTxSheet` |
| 리포트 | 📊 | 월 요약·**AI 월간 브리핑**(예산 대비·카테고리 적정금액·자동 제안)·카테고리 도넛차트(**항목 탭=그 카테고리 내역 시트**, 대출은 이자+원금 '대출·이자' 병합)·6개월 추이·**개인별/공동 지출 분리**(막대 탭=내역 시트)·**통화별 지출**(해외통화 있을 때)·**전월비 급증 인사이트**·예산 임계 경고·**카테고리 [지출｜수입] 토글**(수입 카테고리 구성 도넛) | `renderStats`/`openAiBrief`/`openRepCatTx`/`openRepPersonTx` |

## 거래 (Transactions)

추가/수정/삭제 가능하며 9종 타입을 지원합니다. 각 타입은 잔액에 미치는 효과(`from`에서 차감 / `to`에 가산)가 다릅니다 — 정의는 `public/js/constants.js` 의 `TX_EFFECT`.

| 타입 | 라벨 | 아이콘 | 잔액효과 | 통계(실소비) |
|---|---|---|---|---|
| `income` | 수입 | 💰 | to에 가산 | |
| `expense` | 지출 | 💳 | from에서 차감 | ✅ 기본 포함 |
| `transfer` | 이체 | 🔄 | from 차감 + to 가산 | |
| `prepaid_charge` | 충전 | ⤴️ | from 차감 + to 가산 | |
| `prepaid_spend` | 선불결제 | 🛒 | from에서 차감 | ✅ 기본 포함 |
| `refund` | 환불 | ↩️ | to에 가산 | |
| `point_earn` | 포인트적립 | ⭐ | to에 가산 | |
| `point_spend` | 포인트사용 | ✨ | from에서 차감 | ✅ 기본 포함 |
| `balance_adjustment` | 잔액조정 | 🛠️ | to에 가산(음수 허용) | |

- **실소비 여부**(`isActualExpense`)는 거래별로 override 가능 — 리포트 통계 포함을 제어. **판정(`isActual`, ledger-calc.js)은 소비성 유형(지출·선불결제·포인트사용)만 실소비로 인정하는 타입 게이트** — 수입은 `isActualExpense:true`(실수입 마커)여도 지출 집계에 안 섞임(총지출에 월급이 섞이던 버그 수정, 2026-08). 기본값은 `ACTUAL_DEFAULT`, **거래 시트의 '📊 실제 소비에 포함' 토글**(소비성 유형만 노출, `sActual`→`isActualSet`→buildTx)로 끄면 통계·예산 제외+잔액만 반영(카드 대금 이체·대납 등 — 함께결제 subTx도 본 거래를 따라감).
- **결제수단 콤보 공통 규칙**(`acctOptsHtml(sel, types)`): 유형군 `<optgroup>`(입출금·현금/카드/선불·간편결제/포인트/기타, `ACCT_GROUPS`)+소유자 표기. 거래·정기 시트는 **유형별 필터** — 선불결제=선불류만·**포인트 사용/적립=포인트+간편결제**(네이버페이 등 지갑 포인트, 2026-08)·충전=수단 비선불/대상 선불·포인트(`renderTxDyn`/`renderRecAccts`의 PREPAY/NONPRE).
- **💐 경조사 연결**(`maybeSuggestGiftEvent`/`isGiftCat`): 경조사 카테고리(판정=`type==='event'` **또는 이름에 '경조사' 포함** — 기본 '경조사' 카테고리는 type이 expense라 이름 판정 필수) 지출을 저장하면 **경조사비 장부 기록 제안** — 수락 시 `openGiftEdit` 프리필(금액·날짜)로 열리고 '가계부 거래로도 기록' 스위치를 꺼서 중복 방지(카테고리 선택 시 시트에 안내 문구).
- **💡 계좌별 이번 달 필요액**(자산 카드, `monthAcctNeeds`): **지출성 정기(expense류) + 적금 이체(`savingsId`)**·구독(결제수단)·대출(상환계좌)을 **출금 계좌별 합산**해 "월급날 각 계좌에 얼마 넣을지" 표시(남은 예정 병기). **행 탭=구성 항목 시트(`openAcctNeedSheet`, 2026-08)** — 그 계좌 필요액이 어떤 항목(정기·구독·적금·대출 pill + 이름·날짜·금액)으로 이뤄졌는지 날짜순 표시(지난 회차 흐림+'지남', 남은 예정액·통장 내역 버튼, `monthAcctNeeds`의 `items` 수집). 일반 이체·충전 정기(계좌 간 돈 옮기기·입금성)는 **제외** — 카드 라벨 '정기·구독·적금·대출'과 합산 기준이 일치(예전 debit측 전부 합산이라 월급/파킹 이체가 섞이던 문제 수정). **선불·포인트류 계좌 행도 제외**(2026-08) — 충전으로 채우는 수단이라 "옮겨둘 돈" 안내 대상이 아님. **💳 카드대금 행 추가**(2026-08): 신용카드 사용 잔액(음수)을 '갚아야 할 금액'으로 카드별 병기(카드대금 pill, 탭=카드 통장).
- 거래에는 카테고리·계좌(from/to)·날짜·설명·메모·**소비 대상(user)**·목적별 가계부 연결·카드실적 포함 여부 등이 붙습니다.
- **🧠 최근 선택 기본값**(`txLastOf`/`txLastRemember`/`applyTxLastFor`): 새 거래 시트는 **마지막 저장 때 고른 결제수단(from/to)·소비 대상을 유형별로 기억해 미리 선택**한다(localStorage `txlast:{wsId}:{uid}`, 이 기기·사용자·워크스페이스별). 유형 전환 시 그 유형의 최근값을 **사용자가 아직 손대지 않은 필드에만** 채움(`_touched` 추적 — `onTxAcctChange`/`onTxConsumerChange`가 선택 동기화+손댐 표시). 새 거래 저장 시에만 갱신(수정 제외), 삭제된 계좌·탈퇴 멤버는 무시.
- **⚡ 자주 쓰는 거래 원탭**(`_txTpl`/`applyTxTemplate`): 새 거래 시트 상단에 (유형·설명·카테고리·금액) 빈도 상위 칩 최대 3개(`frequentTxTemplates`, count≥2) — 탭하면 폼 전체 프리필(최근 같은 거래에서 결제수단·소비대상까지 복원).
- **✍️ 설명 자동완성**(`onDescInput`/`renderDescSug`/`applyDescSug`): 새 거래 설명 입력 중 과거 거래에서 같은 성격(지출/수입군)·같은 설명을 최신순 3개 제안, 탭하면 설명+카테고리+수단(+금액칸 비었으면 금액) 유추 채움.
- **🔝 카테고리 칩 빈도순**(`catsByUsage`): 거래 시트 카테고리 칩을 최근 90일 사용 횟수순 정렬(동률=기존 sortOrder, 기본 선택=최다 사용).
- **➕ 저장 후 계속**(`saveTx(keepOpen)`/`saveTxAgain`): 새 거래 전용 보조 버튼 — 저장 후 시트를 유지하고 금액·설명·메모만 비움(날짜·유형·수단·소비대상·함께결제 해제 유지 → 연속 입력). 자동충전이 끼면 그 흐름 우선.
- **🔁 정기거래 자동 제안**(`maybeSuggestRecurring` + 순수 `recurringCandidate` in util.js): 같은 설명·유형·±15% 금액이 **저장한 달 포함 3개월 연속**이면 저장 직후 "매월 N일 정기거래 등록" 확인 시트 — 수락 시 규칙 생성(`lastPosted`=이번 거래 날짜라 다음 달부터 생성). 같은 설명은 수락·거절 무관 1회만 제안(localStorage `recsug`), 동명 활성 규칙·정기 생성분·자동충전 거래는 스킵.
- **🔍 거래 검색 + ☑️ 일괄 편집**(더보기 → 거래 검색, `openTxSearch`/`txMatches`): 키워드(설명·메모·카테고리)·기간·금액범위·유형 필터, 결과 최신순 100건 표시(건수·합계). 행 탭=수정 시트(닫으면 검색으로 복귀, `_sheetReopen`), 데이터 갱신 시 결과만 리렌더(`_sheetRefresh`). **[선택] 모드**(`txsToggleMode`)=행 탭이 선택 토글로 바뀌고 **카테고리·소비대상 일괄 변경(즉시)·일괄 삭제(확인·함께결제 짝/정기 멱등로그 정리)** — `txsBulkCat`/`txsBulkWho`/`txsBulkDel`.
- **📌 이번 달 고정지출 카드**(자산, `monthFixedCosts`): 정기(지출성 타입)·구독(정기 미연결분만 — 이중집계 방지)·적금 납입(savingsId 규칙)을 이번 달 발생 회차(`occurrencesV2`) 기준으로 합산 — 합계·부문별 건수/금액(행 탭=관리 화면)·**오늘 이후 남은 예정액**.
- **🧮 실제 잔액 맞추기**(계좌 시트, `adjustAcctBalance`): 실제 잔액 입력 → 차액만큼 잔액조정 거래(`balance_adjustment`, `isActualExpense:false`) 자동 생성.
- **🏦 계좌 거래내역(통장) 시트**(`openAcctDetail(id, m, mode)`): 자산의 계좌 행·리포트 선불/포인트 잔액 행·카드 실적 목록을 탭하면 **그 계좌의 거래내역**이 열린다(설정 편집은 시트 하단 '설정 수정' 버튼 — 구 '행 탭=편집'에서 변경).
  - **계좌 관점 부호·잔액 추이**: `acctDelta`(= `accountBalance`와 같은 `TX_EFFECT` 규칙 — 출금측 −, 입금측 +)로 입금/출금을 판정해 `acctTxRowHtml`이 **+초록/−빨강 + 그 거래 직후 잔액(`.acct-run`)**을 통장처럼 표시. 이체·충전은 상대 계좌를 `→/←`로. 미래(예정) 거래도 시간순 누적에 포함해 예상 잔액을 보여줌(📅 배지).
  - **월 네비 + 요약**(`acctMonthRows`): 현재 잔액(오늘까지 기준=목록과 동일) + 그 달 입금·출금·순변동·**월말 잔액**. **[통장 | 카테고리] 토글**(카테고리는 `txListHtml(...,'cat')` 공용 묶음 — `forceMode`로 전역 토글과 독립). 카드면 실적 진행률 + **실적 기간으로 보기**(`openCardTxSheet(id,m,'period')`) 바로가기.
  - **+ 이 계좌로 거래 추가**(`addTxForAcct`): 거래 입력을 열고 그 계좌를 결제/출금 수단으로 프리셋(포인트=`point_spend`·선불류=`prepaid_spend`·그 외 `expense`로 유형 자동 전환). 행 탭=거래 수정, 닫으면 이 통장으로 복귀(`_sheetReopen`).
- **🧾 월말 결산 카드**(오늘 홈, `monthlyRecapHtml`): 매월 1~7일에 지난달 총지출·수입·전월비·최다 카테고리 요약 + **'AI 브리핑'**(지난달 `openAiBrief`)·'리포트 열기'(그 달로 이동). 닫으면 localStorage `recap:{wsId}:{월}`로 그 달은 재표시 안 함.
- **✨ AI 월간 브리핑**(`openAiBrief(m)` — 리포트 상단 `.aib-open` 버튼·월말 결산 카드에서 진입): **온디바이스 규칙 기반 자동 분석**(외부 AI 호출 없음). ① 요약 코멘트(`aiBriefTalk` — 예산 초과/근접/여유·전월비·최대 지출처를 문장으로) ② **예산 게이지**(설정예산·사용금액·사용률, 초과 시 빨간 채움+예산 위치 눈금) ③ **카테고리별 사용 vs 적정**(상위 8 — **적정금액 = 예산 × 그 카테고리 사용 비중**(100원 단위), 막대(사용)+눈금(적정)+▲초과/여유 판정. 총예산(`totalMonthlyBudget`) 없으면 카테고리 월예산 합으로 대체) ④ **AI 제안**(`aiBriefTips` — 최대 5개: 최대 초과 카테고리의 다음 달 목표액·전월 급증 카테고리·최대 단일 지출(총지출 15%↑)·구독 고정비 비중·무지출일·저축률). 예산 미설정이면 예산 만들기 버튼 안내. 섹션은 순차 페이드인(`.aib-sec`, reduced-motion 시 정지).
- **📈 예산 페이스 예측**(리포트 예산 카드): 이번 달을 보는 중이고 기간이 15~95% 경과했을 때 `사용률/경과율`로 예상 소진율을 계산, **105% 이상이면 경고 줄** 표시.
- **📅 연간 리포트**(`_repRange`/`yearStatsHtml`): 리포트 상단 **[월간|연간] 토글** — 연간 뷰는 연 총지출·수입·잔액·월평균(올해는 경과 개월 기준), **12개월 막대**(탭=`yearBarTap`으로 그 달 월간 뷰 전환), **카테고리별 연간 합계**(상위 12+비율 바, **[지출｜수입] 토글 공유**). ‹ ›=연도 이동(`statsYearMove`).
- **📊 전월 비교**(월간 리포트): 카테고리별 `지난달 → 이번달 ▲증감` 표(상위 8, 도넛과 동일 집계 — 지출=`repCatSums`(대출 병합 포함)·수입=`repIncSums`).
- **💰 카테고리 [지출 | 수입] 토글**(`_repCatKind`/`setRepCatKind`/`repCatKindSegHtml`): 월간 도넛·전월 비교와 연간 카테고리가 공유 — 수입 모드는 실수입(`isRealIncomeTx` — 대출 원금 수령·원금 회수 제외)만 카테고리 합산, 범례 탭=`openRepCatTx(m,name,etc,kind)` 수입 내역 드릴다운.
- **💾 데이터 백업/복원**(설정, `exportBackup`/`importBackup`): 현재 ws 전체 스냅샷+내 개인 할일을 JSON 파일로 내보내고, 파일 선택→확인 후 각 최상위 항목을 통째 교체(update — 백업에 없는 항목은 유지). **게임(`users/{uid}/game`)은 제외**(재화 조작 방지).
- **소비 대상 분리**: 지출/선불결제/포인트사용 거래는 **출금 수단(어느 계좌에서 나갔나)** 과 **소비 대상(누구의 소비인가)** 을 따로 고릅니다. 소비 대상은 워크스페이스 멤버 또는 **`공동`**(집세 등 공동 비용)으로 지정 — 정기거래에도 동일. 리포트의 "개인별 지출/공동 지출"이 이 값으로 집계됩니다. 멤버일 땐 `userUid` 를 병행 저장해 **동명이인·개명에 견고**(`personKey`).
- **필터·검색**: 타입(지출/수입/이체)·키워드 칩. 목록 상단 **🔍 검색**(`openTxSearch`)은 키워드(내용·**메모**·카테고리) + **기간(from~to)** + **금액(min~max)** + 타입 복합 검색(순수 `txMatches`).
- **💳+✨ 함께결제(포인트·선불 + 카드 한 번에)**: 한 번의 결제를 **포인트·선불로 일부 + 나머지는 카드/계좌**로 낸 경우를 **거래 하나 입력하듯** 기록한다. 지출 시트의 결제 수단 바로 아래 **`포인트·선불 함께` 스위치**(`coPayBlockHtml`/`toggleCoPay`, 선불류 계좌가 하나도 없으면 숨김)를 켜고 **수단 + 포인트 사용액**을 넣으면, 금액칸의 **총 결제 금액**에서 그만큼을 떼어 **거래 2건**으로 저장한다 — 본 거래(`expense`, 총액−포인트분, 원래 결제 수단) + 보조 거래(포인트 계좌면 `point_spend`·그 외 선불류면 `prepaid_spend`, 포인트분). 둘 다 실지출이라 **합치면 총액이 그대로 통계·예산에 반영**되고, 각 계좌 잔액도 실제대로 빠진다.
  - 안내줄(`updateCoPayNote`)이 `총 X원 = 포인트 Y원 + 나머지 Z원` 을 실시간으로 보여주고, 사용액이 총액 이상이면 저장을 막는다(원화 지출에서만 사용 가능).
  - **카드 실적 인정 금액 기본값은 카드로 실제 낸 금액**(총액−포인트분)이라 실적이 부풀지 않는다.
  - 두 거래는 서로 연결된다 — 본 거래 `coPayTxId`·`coPayAmount`·`coPayAcct`, 보조 거래 `coPayMainId`. **본 거래를 다시 열면 총액으로 복원**되어 그대로 수정(스위치를 끄면 짝 거래 삭제)·**삭제하면 짝 거래도 함께 삭제**된다. 보조 거래를 직접 열면 **'본 거래 열기' 안내 배너**가 뜬다. 목록에선 양쪽 행에 `✨ 함께결제` 배지.
  - 목적별 가계부 **정산은 본 거래에만** 붙는다(포인트분은 개인 부담으로 보고 이중 계산 방지). 저장은 두 건을 **한 번의 다중경로 `update()`** 로 써서 한쪽만 남는 일이 없다.
- **예산 사전 경고**: 지출 저장 시 관련 예산이 임계(80% 등)·100%를 **처음 넘으면** 비차단 토스트로 알림(`budgetPreWarn`).
- **이체 분류(곗돈 등)**: 이체 거래도 카테고리를 붙일 수 있음(기본 **곗돈**(🤝) 제공) — 계모임 납입·수령을 이체로 기록해 분류. 이체는 실소비/예산 통계에 미포함이라 지출·수입을 왜곡하지 않음.
- **해외통화(여행용)**: 금액 입력 시 **통화 선택**(USD·JPY·EUR·CNY 등). 외화 선택 시 소수점 입력 가능하고 **환율(원화/1단위)을 입력**하면 원화로 환산돼 저장(`amount`=원화 환산액). 거래에 `currency`·`foreignAmount`·`fxRate`·`fxSource`·`fxDate` 저장, 목록엔 원화+외화 원금 병기. **실시간 환율 자동조회**(frankfurter, 거래일자 반영·일자별 캐시)와 **직접 입력** 모두 지원(🔄 재조회, 실패 시 수동 폴백). 순수 계산 헬퍼 `krwFromForeign`·`fmtForeign`·`sumByCurrency`(`util.js`).
- **CSV 내보내기**: 더보기 → 📤 (`exportCSV`). 해외통화 거래는 `원통화·외화금액·환율·환율원본·환율일자` 컬럼까지 내보내 원본 보존(왕복 가능).

## 달력 / 리포트

- **달력**(`renderCalendar`): 월 네비게이션 + 일별 수입/지출 색점 그리드(`calendarGridHtml` — **시작 요일은 설정 '달력 시작 요일'을 따름**, 기본 월요일·`weekStartSun`/`calHeadHtml`/`calFirstOffset` 공용, 할일 캘린더도 동일) + 선택일 거래(`selectDay`/`selectedDayHtml`). 그룹은 **멤버 칩 필터**(`memberChipRow`/`setMemberFilterByUid`)로 기록자별로 거름. "다가오는 반복결제" 표시.
- **리포트**(`renderStats`): 월 요약·총지출·**CSS 도넛(카테고리)** — **[지출 | 수입] 토글**(`_repCatKind` — 수입 카테고리 구성도 도넛으로)과 **[% | 금액] 토글**(`setRepVal`)로 항목별 비율/실제 금액(원)을 바꿔 봄·6개월 막대·**개인별/공동 지출 분리 바**(`t.user` 집계, `공동` 별도)·**통화별 지출**(해외통화 있을 때)·**전월비 급증 인사이트**·예산 임계 경고·목적별 사용 상위. *Chart.js 미사용 — 순수 CSS 차트.*
- **카테고리 내역 드릴다운**(`openRepCatTx`): 카테고리 범례 항목을 **탭하면 그 달·그 카테고리의 실지출 거래 목록** 시트(합계·건수, 행 탭=거래 수정 시트). 도넛 **'기타'(상위 5개 밖 묶음)** 를 탭하면 묶인 카테고리 전체 내역을 표시(렌더와 동일 기준으로 재계산).
- **🏦 대출 병합 표시**(`repCatSums`): 카테고리 도넛·범례에서 **대출이자(실지출)와 대출 원금 상환(실지출 통계 제외 거래)을 '대출·이자' 한 항목으로 합산**해 대출로 나간 돈을 한눈에 본다(원금 포함 시 안내 문구 표시 — 총지출 카드·예산·인사이트는 종전대로 이자만). 드릴다운은 이자+원금 거래를 함께 나열하고 `이자 X + 원금 Y` 분해 합계를 보여줌. '기타' 묶음 경계도 병합 집계 기준으로 동일하게 계산.
- **👤 개인별/공동 지출 드릴다운**(`openRepPersonTx`): 개인별·공동 지출 **막대를 탭하면 그 달 그 소비 대상의 실지출 거래 목록** 시트(합계·건수). 집계 키는 **`repPersonKey`** — uid 저장 거래와 이름만 저장된 거래(정기 생성분 등)를 멤버 이름 매칭으로 한 사람에 병합(같은 멤버가 막대 두 개로 갈라지던 버그 방지, 멤버 아닌 레거시 이름은 그대로).
- **📚 내역 목록 [카테고리 | 시간순] 토글**(`txListHtml`/`txListSegHtml`/`setTxListMode`): 개인별/공동 드릴다운·카드 내역 시트의 거래 목록은 **기본이 카테고리별 묶음**(카테고리 카드마다 tint 타일+이름+건수+소계 헤더, 그룹=금액순·그룹 안=최신순), 토글로 시간순 한 목록 전환. 토글은 `_sheetReopen` 재호출로 현재 시트를 다시 그림.
- 카테고리 도넛·범례는 **모든 카테고리를 개별 표시**(구 '기타(상위 5개 밖 묶음)' 폐기 — `openRepCatTx`의 etc 분기는 하위호환으로만 남음).
- **↩️ 내역 시트 → 거래 수정 → 복귀**: 거래 목록을 보여주는 시트(일자 `openDaySheet`·카드 내역·카테고리/개인별 드릴다운·정기 생성분·예산/구독/목적별 상세·카드 실적)는 `state._sheetReopen`에 자기 재오픈 함수를 등록하고, `openTxSheet`가 그 위에서 열리면 이를 `state._sheetBackFn`으로 arm → `closeSheet`가 전체를 닫는 대신 이전 목록 시트를 다시 연다(재호출이라 수정·삭제 반영). 목록 시트를 직접 닫으면 평소처럼 닫힘.

## 워크스페이스 (개인 / 그룹 공유)

핵심 — 모든 가계부 데이터는 워크스페이스 단위로 격리됩니다. (공통 기반이라 [features.md](features.md#공통-기반)에도 요약)

- **개인 프로필**: `type:'personal'`, 예약 워크스페이스 `ws_{uid}`(멤버 1명). 항상 존재하도록 자동 보장(`createPersonalWorkspace`, 없으면 로그인 시 생성). 그룹전환에서 **'개인 프로필'**(내 아바타·이름)로 선택 = 나만 보는 개인 가계부·할일. *구 "개인 전용 그룹"을 대체 — 기존 `ws_{uid}` 데이터는 그대로 개인 프로필 저장소로 재사용.*
- **그룹**: `type:'group'` + **6자리 초대코드**. 코드를 아는 사람은 즉시 멤버로 합류(`joinByCode`). 그룹 안에서는 서로의 거래까지 공동으로 읽고 씁니다.
- **멤버 역할**: owner(👑) / member(👤). 관리는 그룹 관리 시트(`openGroupManageSheet`).
- **전환**: 상단 워크스페이스 칩 또는 더보기 → 그룹 전환(`switchWorkspace`, `openWorkspaceSheet`). **가계부·할일은 각각 최근 컨텍스트를 따로 기억**(`recentWs.ledger`/`recentWs.todo`) — 모드를 토글해도 각자 마지막 쓰던 그룹/개인 프로필로 바로 이어짐.
- **나가기/정리**: 마지막 멤버가 나가면 워크스페이스·코드까지 삭제(`leaveWorkspace`).
- **v2→v3 자동 이전**: 구버전 전역 데이터가 있으면 로그인 시 "공유 가계부" 그룹으로 1회 이전(`migrateLegacyIfNeeded`).

## 결제수단 / 자산

- **계좌 타입**: 현금·은행계좌·신용카드·체크카드·선불충전금·포인트·간편결제·상품권·기타 (`ACCT_TYPES`).
- **제공사**: 직접·네이버페이·쿠팡·카카오페이·토스·기타 (`PROVIDERS`).
- **공개 범위**(`visibility`): 전체 공개 / 잔액만 공개 / 개인만 보기 (`VISIBILITY`). UI 단에서 필터링.
- **소유자**: 멤버 이름 또는 "공동". 초기 잔액·색상·메모, 잔액 자동 계산(거래 흐름 반영). **초기 잔액은 음수(부채 계좌, 예: `-100,000`) 입력 가능**(`parseAmountSigned`).
- **선불·포인트** 계좌는 자산 탭에서 별도 잔액 요약. 화면: `renderAssets`·`openAcctSheet`.
- **⚡ 자동충전(선불·포인트·간편결제·상품권)**: 계좌 시트의 **자동충전 설정 카드**(`prepaidCfgHtml` — 출금 계좌+충전 금액, `autoChargeFrom`/`autoChargeAmount`)를 두고, **새 거래로 선불류 잔액이 마이너스가 되면**(`autoChargeCheck` — 예정·수정 거래 제외) ① 계좌·금액 모두 설정 → **충전 거래를 자동 기록**(부족분을 덮을 때까지 설정 금액의 배수, `insertChargeTx`·`autoCharge:true`·토스트) ② 계좌만 설정 → 충전 시트에 계좌 프리셋+금액(부족분) 확인 ③ 미설정 → **충전 입력 시트**(`openAutoChargeSheet` — 출금 계좌·금액 입력, **"자동충전 설정으로 저장" 스위치**로 다음부터 전자동, 건너뛰기 가능). 충전 거래는 카드 출금 시 카드 실적 규칙(`defaultCardIncluded`)도 그대로 적용.

- 거래별 실적 포함 토글·금액·제외 사유, **실적 제외 카테고리**, **선불충전 실적 포함** 옵션.
- 자산 탭과 카드 실적 시트(`openCardList`)에서 진행률 시각화.
- **📅 지난달 카드 내역 보기(리포트)**: 리포트 탭의 **카드별** 섹션은 **월 네비(‹ ›)가 고른 달**을 따른다 — 그 달 카드별 결제액·건수와 실적 진행률(`cardPerformance(card, ref)` — 기준일 `monthRefDate(m)`: 이번 달=오늘, 지난/다음 달=그 달 15일. 카드가 '매월 N일 시작' 커스텀 기간이어도 그 달의 기간을 잡음)을 보여준다. 카드 목록은 **카드 설정(`creditCards`)이 없어도 계좌 유형(`CARD_TYPES`)만으로** 잡아 체크카드·목표 미설정 카드도 나온다(`cardAccounts`), 그 달 결제가 있는 카드만 사용액 순으로.
  - 행을 탭하면 **카드 내역 시트**(`openCardTxSheet(cardId, m, mode)`) — 상단 요약(결제액·건수 + 실적 진행률·실적 기간·제외 건수) + 결제 내역(`expense`/`prepaid_charge`, 최신순). **시트 안에도 ‹ › 이동**이 있어 지난 기간을 이어서 볼 수 있다.
  - **[달력 월 | 실적 기간] 보기 토글**(카드 설정 있는 카드만): 기본은 달력 월 기준(`cardMonthTx`), **실적 기간 모드**로 바꾸면 그 카드의 실적 기간(예: 15일~다음달 14일, `cardPeriod`) 단위로 내역·합계를 보여주고(`cardPeriodTx`) 헤더도 기간 날짜(`2026년 7.15 ~ 8.14`)로 바뀐다. ‹ ›도 실적 기간 단위로 이동. 실적 진행률 블록과 같은 기간이라 합계·내역이 맞아떨어진다.
  - **👥 소비 대상별 분담**(`personSplit`, `repPersonKey` 기준): 카드 내역 시트 상단 요약에 **공동·멤버별 결제 합계**(🤝 공동 X · 현경 Y)를 보여주고, **리포트 카드별 행에도 분담 줄**이 실적 아래 표시된다(그 달 기준).
- **거래 행 표기**(`txRowHtml`): 지출=`카테고리 · 결제수단 · 소비대상`, 수입=`카테고리 · 입금수단`, 이체류=`from → to` — **모든 목록에서 결제/입금 수단이 보인다**(구 "계좌는 상세에서" 정책 폐기).

## 예산 (Budget)

- **총예산** 또는 **카테고리별 예산**. 기간: 주간/월간/연간/사용자지정(`periodType`). 범위: 공동(group)/개인(personal).
- 80% 등 임계치 경고(`alertEnabled`, `alertThreshold`). 진행률 막대 색: 초록(0–80%)→노랑→주황→빨강(100%+) — `budgetColor`.
- **개인(personal) 예산의 초과 사전경고는 소유자 본인 소비에만** 뜬다(`ownerUid` 병행 저장 → `budgetPreWarn`이 가시 예산만·소유자 게이트). 다른 멤버가 같은 카테고리를 써도 남의 개인예산 경고가 뜨지 않음.
- **이월(rollover)**: 지난 기간 미사용분(양수만·1기간)을 이번 기간에 가산. **이월을 켠 시점(`rolloverSince`) 이전 기간은 이월하지 않음** — 갓 만든/갓 켠 예산이 지난 기간을 공짜로 2×이월하지 않게.
- **예정(미래일) 거래는 예산 사용/경고에서 제외**(잔액과 동일 기준) — 아직 안 쓴 돈으로 취급.
- 상세 보기에서 포함 거래 확인(`openBudgetDetail`). 화면: `openBudgetSheet`/`openBudgetEdit`.

## 정기결제 / 반복거래 (Recurring)

- 주기: 매일/매주/매월/매년/사용자지정 + 간격(`interval`). 상태: active/paused/ended. **매년(yearly)은 시작일의 월·일에** 발생(`day`=시작일 일자로 저장).
- **자동 생성**(`autoCreate`) — 로그인 시 도래한 반복거래를 자동 기록하며, `recurringLogs` 멱등 키로 중복 방지.
- 달력에 "다가오는 반복결제" 표시. 편집 `openRecurringEdit`. 구버전 고정지출(`fixedExpenses`)은 자동 이전(`migrateFixed`).

## 구독 (Subscription)

## 공동 지출 정산 (Settlement)

목적별 가계부에서 **정산 사용**을 켠 경우, 그 안의 공동 지출을 정산할 수 있습니다.

- **거래 입력 시 정산**(선택 PB가 `settlementEnabled`일 때만 노출): 정산 포함 토글 → 결제자·분담 방식(균등 분할/직접 입력/결제자 부담)·참여자·참여자별 부담 금액·메모. 함수 `renderSettleBlock`/`collectSettle`. 순수 계산 `computeSettleAmounts`(`util.js`).
- **정산 계산**(`pbSettleSummary`/`settlementSplit`/`greedySettle`): 참여자별 결제(paid)·부담(owed)·잔액(balance), 단순 최소 송금 제안.
- **목적별 상세 [정산] 탭**(`renderPbSettleTab`): 요약·참여자별 잔액·송금 제안+완료 처리·완료 내역+취소·정산 대상 거래.
- **송금 완료**(`saveSettlementPayment`): `settlementPayments` 노드에 기록(기본은 상태만). 옵션으로 실제 `transfer` 거래 동시 생성(실제소비 미포함).
- 더보기 `정산` 메뉴(`openSettlementOverview`)에서 상태 요약. **중복 집계 방지**: 원본 결제 거래만 실제소비 1회 반영, 정산 송금은 통계·예산·리포트에 미포함.

## 대출 / 이자 관리 (Loan)

빌린 돈·빌려준 돈, 이자·상환을 관리합니다. 더보기 → 🏧 대출/이자(`openLoanBook`).

- **대출**(`loans`): 이름·방향(빌림/빌려줌)·상대/기관·원금·연이율(%)·시작/만기일·**상환 방식(`repayType`: bullet 원금만기(기본·하위호환)/amortized 원리금균등/equal_principal 원금균등)**·기본 상환계좌. 잔액·이자는 `loanCalc`로 계산(저장 안 함).
- **🏦 상환 스케줄 자동 계산**(순수 `loanInstallment(P,연이율,n,type,k)` in util.js — 원리금균등 M=P·i·(1+i)ⁿ/((1+i)ⁿ−1)·마지막 회차 잔여 정산, 원금균등 P/n+잔액이자, 원금만기 이자만+만기 원금): 상세에 **📅 이번 달 상환 예정 카드**(`loanMonthPlan` — 회차 k=시작월부터 경과 개월·1회차=시작 다음 달, n=시작~만기 개월, 상환일=시작일 일자 말일 클램프. 원리금균등·원금균등은 만기일 필수 — 없으면 안내), **상환 기록 시트에 이번 달 회차 원금·이자 프리필**, **자산 고정지출 카드에 대출 상환 합산**(빌림·활성·잔액>0만). **신규 대출 시 '원금을 계좌 잔액에 반영' 토글**을 켜면 원금 이동 거래를 자동 생성(빌림=입금 `income`·빌려줌=출금 `expense`, `isActualExpense:false`라 실소비 통계 제외, `loanId`·`principalTxId`로 연결·삭제 시 함께 정리) → 원금 입출금을 따로 입력할 필요 없이 계좌 잔액이 실제와 맞는다.
- **상세**(`openLoanDetail`): 잔액·원금·누적 이자·상환률 바, **월 예상 이자(잔액×연이율/12, 단리)**, 상태(상환중/완료/연체).
- **상환 기록**(`loanPayments`): 원금 상환 + 이자 입력 → 잔액 자동 차감.
- **거래 연결**(기본 ON): **원금·이자 모두** 실제 거래로 연결해 선택 계좌 잔액에 반영. 빌림 → `대출이자` 지출(실제소비)+`대출상환` 지출(원금, `isActualExpense:false`), 빌려줌 → `이자`·`원금회수` 수입. `loanId`로 연결(🏦 배지). **원금(상환·원금회수)은 부채/자산 이동이라 실소비·예산은 물론 리포트/달력 '수입' 집계에서도 제외**(잔액만 반영) → 수입 부풀림·이중집계 없음.

## 적금 (Savings)

- **월 납입식 적금**: 적금명·**월 납입액·연 이율(%)·기간(개월)·매달 납입일·시작일**을 입력하면 **만기일·총 납입 원금·예상 이자(세전/세후)를 자동 계산**해 보여준다(단리, 이자소득세 15.4% — 순수 계산 `savingsPlan` in `util.js`, 회차별 예치개월 합 `n(n+1)/2` 공식). **만기일 = 시작일 + 기간(시작일의 일자 기준·말일 클램프)** — 납입 스케줄(first/last)은 납입일 기준(2026-08 사용자 지침). 입력 시트에서 실시간 미리보기(`svPreview`), 자산 화면 목록에 진행률(납입 회차)·만기일·예상 수령액 표시.
- **💰 시작일 첫 납입 체크(2026-08 — 확인 팝업에서 시트 내 스위치로 개편)**: 신규 등록 시 **시작일의 '일' ≠ 납입일**이면 등록 시트에 **"시작일에 첫 납입 했어요" 스위치**(`svFirstPayRow` — 시작일·납입일 변경 시 실시간 표시/숨김, 체크 상태 유지)가 나타난다. 체크하고 저장하면 ① **출금 계좌 있음** = `postOccurrence` 재사용으로 시작일 이체 1건 즉시 기록(멱등 로그 `rec_sv_*` 중복 없음, 출금·적금 계좌 잔액 반영, `savingsPaid`가 거래 집계로 횟수 +1) ② **출금 계좌 없음** = 적금 계좌에 입금 기록(`balance_adjustment` `sv1_{key}`, 통계 비포함) + **`firstPaid` 마커**로 횟수 추정(`savingsPaid`)에 +1(만기 회차수 클램프, 수정 시 보존). **⚖️ 회차 보정(2026-08 검토 반영)**: 첫 납입이 **1회차**가 되므로 정기 규칙의 `endDate`를 한 달 앞당겨(`svShiftM(plan.last,−1,day)`, 말일 클램프) **총 납입 = 기간(n)회를 유지**한다 — 보정 없으면 가입일 납입+정기 n회로 n+1회가 빠져나가던 문제(n=1이면 정기 0회, 규칙은 이력용). 첫 납입 결과는 저장 토스트에 병기.
- **매달 자동 기록**: 출금 계좌를 고르면 저장 시 **연결 정기거래(이체) 규칙을 자동 생성**(`recurring/{uid}/sv_{id}`, `savingsId` 링크·종료일=마지막 납입일) → 기존 정기거래 엔진(`runRecurring`, 멱등)이 매달 납입일에 이체 거래를 자동 기록한다. 정기결제 목록에서도 일시정지·즉시생성 등 관리 가능. 출금 계좌를 해제하면 규칙 삭제(거래는 유지), 적금 삭제 시 연결 규칙도 함께 삭제.
- **✨ 적금 계좌 자동 생성**: 입금(적금) 계좌 기본값이 '자동' — 저장 시 **적금명으로 은행 계좌(`acc_sv_{id}`, `savingsId` 링크)를 만들어 연결**해 납입 이체가 그 잔액으로 쌓인다(재저장 시 재사용·적금명 변경 시 계좌 이름 동기화). 기존 계좌 선택·'계좌 없이(출금만 기록)'도 가능.
- **납입 실적**: 자동 기록 연결 시 실제 생성된 거래(`recurringId`) 집계, 미연결이면 스케줄상 경과 회차로 추정(`savingsPaid`).
- 구(목표액·현재액) 방식 데이터는 기존 표시를 유지하고, 열어서 저장하면 월 납입식으로 전환. 화면: `openSavingsSheet`.

## 주식 (Stocks)

- **보유 종목 기록**(자산 탭 '주식' 섹션): 종목명·**수량(소수점 허용)·매수 평단가·현재가(수동 갱신)**·메모를 입력하면 **평가금액·평가손익·수익률(%)** 을 계산해 표시하고, **평가액 합계가 순자산·총자산(hero)에 포함**된다(hero에 '주식' 칸). 손익 색은 국내 관례(수익=빨강·손실=파랑, `stockGainColor`).
- **해외 주식**: 통화(USD 등, `CURRENCIES`) + **환율(원/1통화)** 입력으로 원화 환산 — 환율 미입력이면 0 처리해 순자산이 부풀지 않게 방어(저장 시 입력 강제). 목록엔 평단·현재가를 원통화로, 평가금액은 원화로 표시.
- **현재가 수동 갱신**: 외부 시세 API 없음(무빌드·오프라인 PWA 원칙) — 행 탭 → 시트에서 현재가만 고쳐 저장하면 평가·순자산에 즉시 반영. 입력 시트엔 실시간 평가 미리보기(`stkPreview`).
- 데이터: `ws/{wsId}/stocks/{uid}/{id}`(적금과 같은 per-uid), 계산 순수부는 `stockCalc`(util.js, 단위테스트). 화면: `openStockSheet`/`saveStock`/`deleteStock`.

## 권한 / 공동 (Permissions / Shared)

- **멤버/권한 관리**(소유자 전용, 그룹): 설정 → **멤버 · 권한 관리**(`openGroupManageSheet`)에서 그룹 이름 변경(`renameWorkspace`)·소유자 이전(`transferOwnership`)·멤버 내보내기(`removeMember`). **권한은 앱 UI에서만 게이팅**(보안규칙은 그룹 멤버 공동권한 유지).
- **항목별 공개범위/소유자**: 계좌·카테고리·예산·구독·목적별·경조사비·대출·거래 등 **생성 폼마다 공개범위(전체/개인)·소유자 선택**이 있고, 기본값은 `defaultVisibility`/`defaultOwnerName`/`defaultOwnerUid`가 정한다(`ws/{wsId}/settings`의 `wsSettings`가 있으면 그 값, 없으면 폴백: 공개범위=전체, 소유자=그룹은 공동·개인은 본인).
- *(제거됨)* 별도 **'권한 · 공동 설정' 화면**(`openSharedSettings`, 기본값 변경 UI·개인전용 항목 일괄 공개)은 멤버·권한 관리와 중복·저가치라 삭제. 워크스페이스 기본값(`wsSettings`) 저장 구조와 항목별 선택은 그대로 유지.

## 카테고리

- 기본 카테고리는 `buildDefaultCategories` 시딩(신규 기본은 `migrateCategories`가 기존 사용자에도 추가). **기본 카테고리도 수정·삭제 가능**, 삭제한 기본은 `catDeleted/{name}` 툼스톤으로 재시딩 방지.
- 아이콘 그리드+색 스와치로 편집(`openCatEdit`/`saveCat`, `iconKey` 저장). 색/아이콘 렌더는 `catColor`/`catSvgIcon`/`CAT_META`/`CAT_SVG`. 화면: `openCategorySheet`/`renderCatManage`.
