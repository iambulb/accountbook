## 사용 방법

1. **대상 저장소에 전달**: 이 폴더 전체를 대상 저장소 `docs/reference/`(또는 원하는 위치)로 복사한다.
2. `05` 를 대상 저장소의 `CLAUDE.md`(또는 CLAUDE.md에서 링크하는 설계 문서)로 승격하고 `<TODO: 게임 이름/스택>` 을 채운다.
3. 대상 저장소의 Claude Code 세션에 지시: **"docs/reference 의 md들을 전부 읽고(06 → 05 → 01~04 순), 06 확정안과 05 지시문 기준으로 현재 코드를 검토·전면 개선하라. 특히 06 §7 '하지 말 것'과 05 §11 체크리스트를 기준으로 기존 구현과의 충돌 지점을 먼저 보고하라."**
4. **원본 코드가 필요할 때**: 01~04에 eggarden `파일:줄번호` 앵커가 있다. 세션이 eggarden 저장소(`C:\gglee\gglee\eggarden`)를 읽을 수 있으면 그대로 참조, 아니면 필요한 함수(`pxSvg`, `camDepth`, `effPetScale`, `dyeFilterCss`, PiP 워커)를 통째로 복사 — 전부 전역 함수라 의존성이 얕다.

## 확정 설계 요약 (06의 핵심만)

- **전투는 그리드 위 액터 레이어에서**(그리드는 점유·이동 데이터만), 톤은 **투닥거림**(HP바·죽음 연출 금지, 먼지구름+별).
- **연출 자산은 범용 FX 시트 1세트로 조립**(펫별 공격 모션 금지) — 전용 모션은 보스/엘리트 대형 스프라이트만.
- **판정·드랍은 시드 RNG로 선확정**(순수 함수), 연출은 재생 전용 — 스킵·중단 안전.
- **배치 3레이어**: 배경=스킨 키 2개(그리드 금지) / 바닥=점유 겸 이동맵 + **스폰존 예약** / 벽=충돌 없는 장식.
- **방치 코어**: 접속 시 결정론 시뮬(경과시간+시드, 상한 8~12h) → **캠 타임랩스 리플레이**로 보여주고 일괄 정산.
- **고도화 순서**: ①가구 버프·시너지·소환 조건(배치의 전략화) → ②타임랩스 → ③흔적 수거·낮밤·날씨 → ④줌/팔로우캠·포토 모드. 방 확장·소셜은 v2.
- **v1 구현 순서**: 점유맵+스폰존 → 방문객(전투 없음) → FX+투닥 연출 → 판정·드랍 → 보스 티어.

## 이식 우선순위 요약

**그대로 가져가도 되는 것(검증된 순수 로직·패턴)**
- 원근 상수 세트 `CAM` + `camDepth`/`camFurnBottom`/`camZ` — 깊이 가림(Y-sort 상당)이 내장.
- 격자 좌표계(`"r_c"` 셀 키, footW×footH 펼침), `areaFree`/`occupiedCells` 충돌 판정, `normRoom` 정규화 패턴.
- 롱프레스 드래그 게이트(250ms/12px) + 스크롤 잠금 + 실패 안전 해제.
- 액터 엔진 뼈대: 단일 rAF, `setXform`(transform-only), `actorShowMoving/Still` 2함수 불변식, goal 접근 로직(→ 전투 APPROACH의 원형).
- `effPetScale` 크기 압축, `pxSvg` 도트 렌더, `pkRand`/`pkSlots` 결정적 난수, 드랍(탭 수거) 인프라.
- PiP 파이프라인 전체, 염색 `dyeFilterCss` + `rollDye`.

**새로 설계·추가하는 것(06 확정안)**
- 점유맵의 이동 차단 겸용, 스폰존 예약, 카탈로그 게임화 필드(useAnchor/action/buffs/theme/summon).
- 손님 스포너·스케줄러·상태기계, 투닥 전투 상태(APPROACH/SCUFFLE/RESULT) + 범용 FX 시트.
- `resolveBattle`/`simulateAway`/`roomScore` 순수 함수군, 타임랩스 재생 모드, 낮/밤·날씨·흔적 시스템.
