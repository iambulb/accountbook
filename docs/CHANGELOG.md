### 변경 — 🐈 캠 펫 움직임 안정화: 가구로 가는 펫 끼임 방지 + 도망(flee) 제거
- **겹침분리 축소**: `separatePets`를 **자유 로밍 펫끼리만** 적용(`mov`=roam 전용, 스킵을 "둘 다 로밍일 때만"). 가구로 가는(goal)·앉은(pause) 펫은 분리에서 제외 → 가구로 가던 펫이 다른 펫에 막혀 제자리 버벅이던 것 해소. 이제 불필요한 `a.parked`(3곳) 제거.
- **도망(flee) 제거**: 작은 펫이 3배 이상 큰 펫을 피해 뒤돌아 질주하던 동작 전부 삭제 — 벽 코너에서 방향 뒤집어 좌우 왕복(춤)하던 원인 하나 제거. 방향전환 쿨다운(`FLIP_COOL`)은 유지. `sw.js` `v3.137.1`.

- **근본 원인**: 이동 액터는 매 프레임 **① 위치 변경**(`left` 또는 `transform`)과 **② `background-position` 프레임 애니**를 동시에 수행하는데, `background-position` 애니는 **합성이 안 되고 항상 메인스레드에서 리페인트**된다. 두 메인스레드 페인트원이 매 프레임 경쟁하다 iOS/크롬이 **한 프레임 페인트를 드롭** → 빈(투명) 프레임이 새어 나옴. 카드는 이동이 없어 페인트원이 `background-position` 하나뿐이라 안 깜빡였다.
- **지난 4번의 시도가 실패한 이유**: (1) 정수 스냅 (2) transform 이동 (3) JS 프레임 구동 (4) 강제 합성 레이어(translateZ/backface) — **모두 프레임 전환을 `background-position`(메인스레드 페인트)으로 유지**해 경쟁의 한 축을 제거하지 못했다. 4번은 오히려 레이어 격리를 늘려 악화.
- **수정**: 걷는 동안 **메인스레드 페인트를 0으로** 만든다. ⑴ 프레임 전환을 `background-position` → **안쪽 필름(`.csprf`, 288×48 스트립)을 `transform:translateX`로 미는 방식**(`@keyframes csprFilm`)으로 교체(합성). ⑵ 액터 이동도 `left` → **`transform:translate3d`**(합성)로. 방향 뒤집기(scaleX)·상호작용 올림(lift)까지 **transform 하나(`setXform`)**로 통합. `.cspr`는 한 프레임 크기의 창(`overflow:hidden`)이 되고, 쉴 때만 정지 스틸을 배경으로 보여준다. → 이동·걷기 모두 GPU 합성이라 페인트 경쟁이 사라져 깜빡임 근본 제거. `sw.js` `v3.78.0`.
