# 🎨 UI 리디자인 — 남은 작업 리스트

새 시안([design/project/가계부 앱.dc.html](../design/project/가계부%20앱.dc.html))을 우리 앱(`public/`)에 1:1로 적용하는 작업의 진행/잔여 항목입니다. **한 화면씩 시안과 1:1로 통째 재현 → 검증 → 커밋** 방식으로 진행합니다.

> 작업 규칙(고정): 화면마다 ① 현재 코드 vs 시안 비교표 합의 → ② 구현 → ③ 시안 일치 시 확인 → ④ 커밋 → ⑤ 다음 화면. 시안 내부 구조(DCLogic/x-dc)는 베끼지 않고 **시각 결과만** 재현. 시안의 가짜 데이터는 **실제 RTDB/기능에 연동**하고, 우리 고유 기능은 빼지 않는다. 정적 파일 추가 시 `sw.js` `APP_SHELL`+`CACHE_VERSION`, `CHANGELOG`·`code-structure` 갱신.

## ✅ 완료 (main 반영)

- **디자인 토큰** — 잉크(블랙↔다크 반전) 주색 + 토스풍(흰 배경+soft 회색 박스)+컬러 액센트, 라이트/다크 CSS 변수(`styles.css`).
- **달력(`renderCalendar`)** — 멤버 칩 가로 스크롤(그라데이션 아바타+필터), `msum` 요약, 월요일 시작 그리드+카테고리 색 점, 선택일 인라인 거래.
- **거래 입력 시트(`openTxSheet`)** — 유형 세그·큰 금액·카테고리 칩(색 점)·필드 행·숫자 키패드 + 「상세 설정」 접기(목적별·정산·카드실적·메모).
- **탭바 SVG 아이콘 + 더보기(`renderMore`)** — 탭바·FAB SVG 라인 아이콘, 프로필 행+4열 기능 그리드+설정 리스트.
- **리포트(`renderStats`)** — 월 네비 + 총지출 카드 + CSS `conic-gradient` 도넛 + 6개월 막대 + 멤버별 바. 예산·목적별·선불 카드 유지. **Chart.js 제거**(순수 CSS 차트).
- **자산(`renderAssets`)** — 순자산 다크 hero(총자산/카드대금/계좌 수) + `.sech`/`.addbtn` 섹션 + 유형별 SVG 계좌 아이콘(`acctIcon`) + 카드 실적 `.perfrow` + 적금 목표 `.bgrow`.

## ❓ 보류된 결정 / 한계 (테스트하며 확정)

- **카테고리 칩**: 실제 16개 → 가로 스크롤. 자주 쓰는 것 상단 고정 / 펼침 보기 옵션 검토.
- **금액 `₩` 표기** 유지 여부(시안은 생략).
- **더보기 그리드에 카드실적·선불/포인트** 노출 여부(현재 자산 탭에서만 접근).
- **멤버 칩/멤버별 지출 필터가 이름(`t.user`) 기반** → 동명이인·이름 변경 시 한계. 정확 귀속 필요하면 거래에 `recorderUid` 도입 검토.
- **키패드 금액 직접 타이핑** 허용 여부(현재 온스크린 키패드 전용).

## 🧪 운영 테스트 체크포인트

- 로컬: `npx serve public` → 실제 RTDB로 달력 · 거래입력 · 더보기 · 다크모드 · 그룹/개인 전환 확인.
- 웹 배포: `npx netlify-cli deploy --prod` (현재까지 리디자인 변경에 **RTDB 규칙 변경 없음**).
